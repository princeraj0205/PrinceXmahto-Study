Op-Amp Basics

An operational amplifier is a high-gain differential amplifier. In an idealized model, input current is treated as approximately zero and negative feedback is used to control closed-loop gain. Inverting configuration gives a phase inversion; non-inverting configuration preserves phase.

DAC and ADC

DAC converts a digital code into an analog quantity. ADC converts an analog signal into a digital representation. Applications include measurement, audio, instrumentation and embedded systems. For an n-bit converter, the number of possible digital codes is 2ⁿ.

RAM

RAM is read/write memory used for working data. It is volatile in common semiconductor implementations. Major categories include SRAM and DRAM; SRAM uses flip-flop-like storage while DRAM stores charge and needs refresh.

ROM

ROM is non-volatile memory used to retain information without continuous power. Types include PROM, EPROM and EEPROM; their programming/erasing mechanisms differ.
