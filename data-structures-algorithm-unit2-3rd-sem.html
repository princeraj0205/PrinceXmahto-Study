DEEP TOPIC 1

2.1 Array & String — Core Notes

Array ek same-type elements ka indexed collection hai. 1-D array me element access A[i] direct hota hai, isliye access O(1) hota hai. Middle me insertion/deletion ke liye elements shift karne pad sakte hain, isliye worst case O(n). 2-D array ko rows × columns form me represent karte hain. Dynamic array size badhne par larger memory block me elements copy kar sakta hai. String characters ka sequence hai; traversal, concatenation, slicing aur comparison common operations hain.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 2

2.2 Linked List — Operations

Singly linked list me har node = data + next reference. Traversal head se NULL tak hota hai. Beginning insertion O(1) ho sakta hai: new.next=head; head=new. Given node ke baad insertion me link update karna hota hai. Deletion me previous node ka next bypass karwate hain. Circular linked list me last node ka next head ko point karta hai, isliye NULL nahi milta; traversal ko stopping condition ke saath likhna zaroori hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 3

2.3 Stack — Infix/Postfix

Stack LIFO follow karta hai. Push top par insertion, pop top se deletion aur peek top ko read karta hai. Array implementation me top=-1 se start kar sakte hain. Infix expression A+B ko postfix AB+ banane ke liye operator precedence aur parentheses handle karte hain. Postfix evaluation me operand mile to push, operator mile to b=pop(), a=pop(), result=a operator b, phir push. Symbol balancing me opening bracket push aur matching closing bracket par pop karke check kiya jata hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 4

2.4 Queue — Enqueue/Dequeue

Queue FIFO follow karta hai. Enqueue rear par aur dequeue front se hota hai. Simple array queue me repeated dequeue ke baad starting positions unused reh sakti hain; circular queue front/rear ko modulo capacity se wrap karke space reuse karta hai. Linked-list queue me front aur rear references rakhne se enqueue/dequeue efficient ban sakte hain.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
