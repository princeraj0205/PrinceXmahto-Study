Sequence Data Types ka Basic Idea

Python mein kuch data types multiple values ko ek saath store karne dete hain. String, List aur Tuple sequence types hain. Inmein elements ko position/index ke through access kiya ja sakta hai.

TypeExampleBasic nature
String"Python"Characters ka sequence; immutable
List[10,20,30]Ordered collection; mutable
Tuple(10,20,30)Ordered collection; immutable
Set{10,20,30}Unique elements ka collection
Dictionary{"name":"Prince"}Key-value mapping
Memory Trick: String = text, List = changeable collection, Tuple = fixed collection, Set = unique values, Dictionary = key → value.

3.1 String

String characters ka sequence hota hai. Python mein string ko single quotes, double quotes ya triple quotes mein likh sakte hain.

s1 = 'Python'
s2 = "Programming"
s3 = """This is
a multiline string"""

String ke characters ordered hote hain, isliye indexing aur slicing possible hai. String immutable hoti hai, yani existing string ke individual character ko directly change nahi kar sakte.

String Indexing

Index ka use string ke kisi particular character ko access karne ke liye hota hai. Python mein indexing 0 se start hoti hai.

word = "PYTHON"

print(word[0])   # P
print(word[1])   # Y
print(word[5])   # N
print(word[-1])  # N
print(word[-2])  # O
CharacterPositive IndexNegative Index
P0-6
Y1-5
T2-4
H3-3
O4-2
N5-1
Important: word[6] jaise invalid index par IndexError aa sakta hai.

String Operations

1. Concatenation

Do strings ko + operator se join karna concatenation hai.

first = "Prince"
last = "Raj"
name = first + " " + last
print(name)

Output: Prince Raj

2. Repetition

* operator se string ko multiple times repeat kar sakte hain.

print("Hi " * 3)

Output: Hi Hi Hi

3. Membership

in aur not in check karte hain ki koi character/substring present hai ya nahi.

text = "Python Programming"

print("Python" in text)       # True
print("Java" in text)         # False
print("Java" not in text)     # True

4. Slicing

Slicing se string ka ek portion nikalte hain.

word = "PYTHON"

print(word[0:3])   # PYT
print(word[2:6])   # THON
print(word[:4])    # PYTH
print(word[3:])    # HON
print(word[::2])   # PTO
print(word[::-1])  # NOHTYP
Slicing rule: string[start:stop:step] mein start generally included aur stop excluded hota hai.

String Traversing using Loops

Traversal ka matlab string ke characters ko ek-ek karke process karna.

word = "PYTHON"

for ch in word:
    print(ch)

Har iteration mein ch ko ek character milega.

String immutable kyun important hai?

word = "Python"

# word[0] = "J"   # Error: string immutable

Character ko direct replace karne ke bajay new string create karni hoti hai.

word = "Python"
word = "J" + word[1:]
print(word)   # Jython

3.2 Lists

List ek ordered collection hai jisme multiple items store kiye ja sakte hain. List square brackets [] mein likhi jati hai.

marks = [70, 82, 91, 65]
names = ["Aman", "Riya", "Prince"]
mixed = [10, "Python", 3.5, True]

List mein different types ke values bhi store ho sakte hain.

List indexing

numbers = [10, 20, 30, 40]

print(numbers[0])    # 10
print(numbers[-1])   # 40

List mutable hoti hai

List ke existing elements ko change kar sakte hain.

numbers = [10, 20, 30]
numbers[1] = 99
print(numbers)

Output: [10, 99, 30]

List Operations

Concatenation

a = [1, 2]
b = [3, 4]
print(a + b)   # [1, 2, 3, 4]

Repetition

a = [1, 2]
print(a * 3)   # [1, 2, 1, 2, 1, 2]

Membership

numbers = [10, 20, 30]
print(20 in numbers)       # True
print(50 not in numbers)   # True

Slicing

numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])  # [20,30,40]
print(numbers[:3])   # [10,20,30]
print(numbers[::2])  # [10,30,50]

List Traversal

marks = [70, 82, 91]

for mark in marks:
    print(mark)

Index ke saath traversal:

marks = [70, 82, 91]

for i in range(len(marks)):
    print(i, marks[i])

List copy ka basic point

a = [1, 2, 3]
b = a.copy()
b.append(4)

print(a)  # [1, 2, 3]
print(b)  # [1, 2, 3, 4]

Linear Search on List

Linear search mein list ko beginning se end tak sequentially check kiya jata hai. Target milte hi search stop ki ja sakti hai.

numbers = [12, 45, 18, 27, 33]
target = 27
found = False

for i in range(len(numbers)):
    if numbers[i] == target:
        print("Found at index", i)
        found = True
        break

if not found:
    print("Not Found")
First item→Compare target→Match?→Found / Next item

Frequency Counting

Frequency ka matlab kisi element ke kitni baar appear hone ki counting.

numbers = [2, 3, 2, 5, 2, 3]
target = 2
count = 0

for x in numbers:
    if x == target:
        count += 1

print("Frequency =", count)

Output: Frequency = 3

3.3 Tuples

Tuple bhi ordered collection hai, lekin tuple immutable hota hai. Tuple generally parentheses () mein likha jata hai.

t = (10, 20, 30)
print(t[0])
print(t[-1])

Creating and Initializing Tuple

t1 = ()
t2 = (10, 20, 30)
t3 = ("Python", 3, True)

# Single-item tuple ke liye comma important hai
t4 = (10,)
Important: (10) normal integer expression hai; (10,) one-element tuple hai.

Tuple Assignment

Python mein multiple values ko ek saath assign/unpack kar sakte hain.

a, b, c = (10, 20, 30)

print(a)
print(b)
print(c)

Tuple operations

a = (1, 2)
b = (3, 4)

print(a + b)   # (1,2,3,4)
print(a * 2)   # (1,2,1,2)
print(2 in a)  # True

Slicing bhi possible hai:

t = (10, 20, 30, 40, 50)
print(t[1:4])

Tuple methods and built-in functions

Method/FunctionUse
len()Tuple length
count()Value ki occurrences
index()First matching value ka index
min()Minimum value
max()Maximum value
sum()Numeric values ka sum

Nested Tuples

Jab tuple ke andar ek aur tuple ho, use nested tuple bolte hain.

t = ((1, 2), (3, 4), (5, 6))

print(t[0])
print(t[1][0])

Yahan t[1][0] ka matlab second inner tuple ka first element hai.

3.4 Set

Set unique elements ka collection hai. Duplicate values automatically eliminate ho jati hain.

s = {10, 20, 20, 30}
print(s)

Result mein 20 ek hi baar rahega. Set create karne ke liye curly braces {} use kiye ja sakte hain. Empty set ke liye set() use karna chahiye.

empty_set = set()

Set Traversing

s = {10, 20, 30}

for x in s:
    print(x)

Set ka main purpose unique values aur set operations hai; sequence-style positional indexing par depend nahi karna chahiye.

Adding and Removing Data

s = {10, 20}

s.add(30)
print(s)

s.remove(20)
print(s)

remove() specified element absent hone par error de sakta hai. discard() absent element par error nahi deta.

s = {10, 20}
s.discard(50)   # no error

Set Operations

SBTE syllabus mein join, union, intersection aur difference jaise set operations included hain. fileciteturn39file1

Union

Union dono sets ke unique elements ko combine karta hai.

A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)
# {1,2,3,4,5}

Intersection

Intersection sirf common elements deta hai.

A = {1, 2, 3}
B = {3, 4, 5}

print(A & B)
# {3}

Difference

A - B mein woh elements milte hain jo A mein hain but B mein nahi.

A = {1, 2, 3}
B = {3, 4, 5}

print(A - B)
# {1,2}

Join

Do sets ko combine karne ke context mein union operation use kiya ja sakta hai.

OperationOperatorMeaning
Union|Dono sets ke unique elements
Intersection&Common elements
Difference-First set ke non-common elements

3.5 Dictionary

Dictionary data ko key-value pair mein store karta hai. Curly braces ke andar entries likhi jati hain.

student = {
    "name": "Prince",
    "branch": "CSE",
    "semester": 3
}

Yahan name, branch aur semester keys hain, aur unke corresponding values stored hain.

Accessing items using keys

student = {"name": "Prince", "semester": 3}

print(student["name"])
print(student["semester"])

Key ke through value access hoti hai. Dictionary ko sequence ki tarah numeric index se access nahi karna chahiye.

Dictionary is mutable

Dictionary mein existing value modify aur new item add kar sakte hain.

student = {"name": "Prince", "semester": 3}

student["semester"] = 4       # modify
student["college"] = "GP Gaya" # add

print(student)

Dictionary built-in methods/functions

MethodUseExample
keys()All keysd.keys()

items()Key-value pairsd.items()
get()Key se value safely accessd.get("name")
update()Items add/modifyd.update({"age":18})
pop()Specified key removed.pop("age")
clear()All entries removed.clear()
len()Number of key-value pairslen(d)

Dictionary traversal

student = {"name": "Prince", "branch": "CSE"}

for key in student:
    print(key, student[key])

Key aur value dono ke liye:

for key, value in student.items():
    print(key, ":", value)

Dictionary vs List

Items position/index se access.Items key se access.
a[0]d["name"]
