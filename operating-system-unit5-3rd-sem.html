5.1 File: Concepts, Attributes, Operations, Types & File-System Structure

File related information ka named collection hai jo secondary storage par persistently store ho sakta hai. File system files ko naming, organization, metadata aur storage allocation ka framework deta hai.

Typical attributes: name, identifier, type, location, size, protection/permissions, timestamps and ownership-related information. Exact attributes OS/file system ke according vary kar sakte hain.

Common operations: create, open, read, write, reposition/seek, close, delete and truncate. File types ko extension/format ya OS-level classification ke basis par identify kiya ja sakta hai, jaise text, executable, image, document etc.

User request → File-system interface → Metadata/permission check → Storage blocks → Data transfer → Result

5.2 Access Methods

Sequential Access

Data ko sequence/order mein process kiya jata hai. Reading next record/position ki direction mein naturally continue kar sakti hai.

Direct Access

File ke particular block/record position ko directly locate karke access kiya ja sakta hai. Databases aur random-access workloads mein useful concept.

Swapping OS memory management ka process hai jisme process ko temporarily main memory se backing storage par move karke later wapas laaya ja sakta hai. Syllabus mein ise file access methods ke saath list kiya gaya hai; exam answer mein ise memory/process-management context ke roop mein clearly define karna chahiye.

5.3 File Allocation Methods

MethodBasic ideaMain point
ContiguousFile ke blocks consecutive disk locations mein.Sequential/direct access simple; external fragmentation issue ho sakta hai.
LinkedFile blocks pointers ke through linked.Non-contiguous blocks possible; direct/random access comparatively less convenient.
IndexedIndex block file ke data-block addresses maintain karta hai.Direct access support; index storage overhead hota hai.

5.4 Directory Structures

  • Single-level: ek common directory; simple but naming conflicts/scalability issues.
  • Two-level: user-wise separate directory level; isolation better.
  • Tree-structured: root se hierarchical subdirectories/files; large systems ke organization ke liye suitable.

Directory ka purpose file names ko organize karna, path-based identification support karna aur access/management ko structured banana hai.

5.5 Disk Organization & Disk Structure

Physical structure disk hardware ke actual storage organization ko refer karta hai. Logical structure file system ke perspective se disk ko blocks, partitions, file-system metadata aur logical storage units mein organize karne ka view deta hai. Exam mein physical vs logical distinction ko clear language mein likho: physical = hardware/storage layout; logical = OS/file-system organization.

Unit 5 — File and Disk Management

Files, access methods, allocation, directories and disk concepts in exam-ready form.

5.1 File Concept

File named collection of related information hai. File metadata me name, type, size, location, protection and timestamps jaise attributes ho sakte hain. OS file operations—create, open, read, write, seek, close, delete—provide karta hai.

5.2 Access Methods

Sequential: records order me access. Direct/random: required position directly access. File type/application ke according suitable method choose hota hai.

5.3 Directory

Directory files ko organize aur locate karne ke liye names-to-metadata mappings maintain karti hai. Common structures: single-level, two-level, tree-structured and graph-oriented concepts.

5.4 File Allocation

Contiguous: blocks together; fast sequential/direct access but external fragmentation/growth issues. Linked: blocks linked; no need for contiguous placement but direct access slower. Indexed: index block pointers store karta hai; supports direct access with index overhead.

5.5 Protection

Access control determine karta hai kaun file ko read/write/execute kar sakta hai. Permissions and ownership concepts file security ke basic tools hain.

5.6 Disk Basics

Disk performance seek time, rotational latency and transfer time se affect ho sakti hai. Scheduling ka objective movement/time ko manage karna hota hai.

5.7 Exam Comparison

Contiguous: simple/fast but fragmentation. Linked: flexible growth but pointer overhead. Indexed: direct access support but index space overhead. Answer me advantage + disadvantage dono likho.
