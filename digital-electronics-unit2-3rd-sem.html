TEXTBOOK DEEP DIVE

Unit 2 — Combinational and Sequential Logic Circuits

SBTE scope includes adders/subtractors, MUX/DEMUX, encoder/decoder, combinational vs sequential logic, SR/JK/T/D and master-slave JK flip-flops, shift registers and ripple/ring counters. fileciteturn308file0

Arithmetic Circuits

Half adder: Sum=A⊕B, Carry=A·B. Full adder: three inputs A,B,Cin; Sum=A⊕B⊕Cin and Carry=AB+Cin(A⊕B). Subtractors use XOR/AND/OR combinations to generate Difference and Borrow.

Multiplexer & Demultiplexer

A MUX selects one of multiple inputs and routes it to a single output using select lines. A 2:1 MUX has one select line; a 4:1 MUX has two. A DEMUX performs the reverse routing: one input is directed to one of several outputs.

Encoder & Decoder

An encoder maps one active input among many to a coded output. A decoder maps a binary input code to one of several output lines. Mention priority encoding when the specification permits multiple active inputs.

Flip-Flops

SR stores a bit using set/reset inputs; JK removes the invalid SR combination by toggling when J=K=1; T toggles when T=1; D transfers D to Q at the active clock edge. A master-slave JK arrangement helps control race-around behavior.

Shift Registers & Counters

SISO shifts serial data through stages. Counters generate a sequence of states. Asynchronous/ripple counters propagate clocking stage by stage; synchronous counters clock stages together. A ring counter circulates a bit pattern through flip-flops.

Exam focusTruth tables, equations, MUX/DEMUX diagrams, flip-flop characteristic tables, synchronous vs asynchronous counters and ring-counter block diagram.
