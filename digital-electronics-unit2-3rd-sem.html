1. Combinational vs Sequential

Combinational circuit ka output present input par depend karta hai; sequential circuit me previous state/storage bhi relevant hota hai.

CombinationalSequential
No storage stateState/storage behavior
Adder, MUX, decoderFlip-flop, register, counter

2. Half & Full Adder

Half adder: S=A⊕B, C=AB. Full adder A, B aur Cin add karta hai.

FA: S=A⊕B⊕Cin
Cout=AB+ACin+BCin

Full adder ko two half adders + OR gate se construct kiya ja sakta hai.

3. Half & Full Subtractor

Half subtractor: D=A⊕B, Bout=A̅B. Full subtractor me Bin bhi hota hai.

FS: D=A⊕B⊕Bin
Bout=A̅B+A̅Bin+BBin

4. Multiplexer

MUX many inputs me se select lines ke basis par one output choose karta hai. 2:1 MUX me one select line.

2:1 MUX: Y=S̅I0+SI1

4:1 MUX me 2 select lines aur 4 data inputs hote hain. Applications: data selection/routing and logic implementation.

5. De-Multiplexer, Encoder & Decoder

DEMUX one input ko selected output line par route karta hai. 1:2 me one select line, 1:4 me two select lines. Encoder input pattern ko code me convert karta hai; decoder coded input ko selected output activation me convert karta hai.

6. Flip-Flops

TypeCore behavior
SRSet/Reset storage
JKJ=K=1 → toggle
TT=1 → toggle; T=0 → hold
DNext state follows D at active clock
Master-Slave JKTwo-stage timing arrangement

7. Shift Registers

Clock pulses ke saath data shift hota hai. Four types exactly yaad rakho:

  • SISO: Serial In → Serial Out
  • SIPO: Serial In → Parallel Out
  • PISO: Parallel In → Serial Out
  • PIPO: Parallel In → Parallel Out

8. Counters

MOD-N counter N states cycle karta hai. Asynchronous/ripple counter me changes stage-to-stage propagate hote hain; synchronous counter me common clocking hoti hai. Syllabus ripple up/down aur ring counter ko specifically cover karta hai. Ring counter shift-register feedback se circulating state pattern banata hai. fileciteturn511file3

⚡ Quick Revision

HA: S=A⊕B, C=AB.
FA: add Cin; memorize S and Cout.
HS/FS: difference + borrow.
MUX: many → one selected output.
DEMUX: one → selected output.
FF: SR, JK, T, D, Master-Slave JK.
Registers: SISO, SIPO, PISO, PIPO.
Counters: MOD, ripple, ring.
