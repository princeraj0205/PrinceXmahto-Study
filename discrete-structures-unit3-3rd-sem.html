3.1 Fundamental Counting Principle

If one task can be done in m ways and an independent second task in n ways, together they can be done in m×n ways. For successive choices, multiply; for mutually exclusive alternatives, add.

3.2 Permutations and Combinations

nPr = n!/(n-r)!    nCr = n!/[r!(n-r)!]

Permutation is arrangement where order matters. Combination is selection where order does not matter. Repeated letters in a word require division by factorials of repeated counts when counting distinct arrangements.

3.3 Pigeonhole Principle

If more than n objects are placed into n boxes, at least one box contains at least two objects. The syllabus specifies applications without proof, so focus on recognizing the “objects vs boxes” mapping and stating the conclusion.

3.4 Binomial Theorem

(x+y)^n = Σ(k=0→n) C(n,k)x^(n-k)y^k

Binomial coefficients are symmetric: C(n,k)=C(n,n−k). In expansion questions, identify the required term/power before substituting k.

3.5 Generating Functions

A generating function represents a sequence as coefficients of a formal power series, e.g. a₀+a₁x+a₂x²+…. It provides an algebraic way to encode counting sequences and solve recurrence/counting problems.

Exam focusFCP word problems, nPr/nCr, repeated-letter arrangements, pigeonhole applications, binomial coefficients/terms and basic generating-function representation.

Unit 3 — Combinatorics & Generating Functions

Counting principles, permutations, combinations, pigeonhole, binomial theorem and generating functions.

3.1 Counting Principles

Sequential independent stages ke choices multiply hote hain; mutually exclusive alternatives add hote hain. Problem ko stages/cases me break karna first step hai.

Product rule: m×n. Sum rule: m+n for exclusive cases.

3.2 Factorial

n!=n(n−1)…1 and 0!=1. Arrangement formulas factorial par based hain.

3.3 Permutation

Order matters: P(n,r)=n!/(n−r)!. All n distinct objects: n! arrangements.

3.4 Combination

Order does not matter: C(n,r)=n!/[r!(n−r)!]. Also C(n,r)=C(n,n−r).

3.5 Pigeonhole Principle

More than n objects into n boxes ⇒ some box contains at least 2. Generalized: more than nk objects in n boxes ⇒ some box contains at least k+1.

3.6 Binomial Theorem

(x+y)n=Σ C(n,k)xn−kyk

Specific coefficient ke liye powers ko target exponent se match karo. Pascal triangle coefficients generate kar sakta hai.

3.7 Generating Functions

Sequence a₀,a₁,… ko A(x)=a₀+a₁x+a₂x²+… formal power series se encode kiya ja sakta hai. Coefficients sequence information carry karte hain.

3.8 Worked Examples

5 students se 2 representatives: C(5,2)=10. President + secretary distinct posts: P(5,2)=20.

3.9 MCQs

Order matters? Permutation
Order not matters? Combination
0!? 1

3.10 Exam + Viva

Question ko pehle identify karo: sequence? arrangement? selection? guaranteed occurrence? coefficient? Then correct principle/formula apply karo.
