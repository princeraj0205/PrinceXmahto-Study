Unit Overview — Algebra

Algebra engineering mathematics ka ek fundamental part hai. Is unit mein hum numbers ko systematically represent karne ke liye determinants, matrices aur vectors ka use karte hain. In tools ki help se multiple unknowns wali equations solve karna, quantities ko organize karna aur direction-based quantities ko mathematically handle karna easy hota hai.

Determinant

Determinant ek numerical value hai jo square matrix se obtain hoti hai. Ye matrix ki properties aur simultaneous equations ki solvability samajhne mein useful hai.

Matrix

Matrix numbers ya quantities ka rectangular arrangement hai. Engineering calculations mein data aur equations ko compact form mein represent kiya ja sakta hai.

Vector

Vector aisi quantity hai jisme magnitude ke saath direction bhi hoti hai. Isliye force, displacement aur velocity jaise concepts ko represent karne mein vector algebra useful hai.

Topic 01

Determinants — Concept and Properties

1.1 Introduction

Determinant ko simple language mein square matrix se associated ek single numerical value samajh sakte hain. Determinant sirf square matrix ke liye define kiya jata hai. Iska notation generally |A| ya det(A) hota hai.

Definition A determinant is a scalar value obtained from the elements of a square array according to a specified mathematical rule.

1.2 Determinant of Order 2

Agar two-row aur two-column arrangement ho:

a b
c d
Order 2 determinant |A| = | a b |
| c d |

|A| = ad − bc

Yahan a, b, c, d matrix ke elements hain. Product ad principal diagonal se aata hai aur bc other diagonal se.

Important terminology

  • Order: Rows × Columns.
  • Element: Matrix ke andar individual entry.
  • Square matrix: Rows aur columns ki number equal.
  • Determinant: Square matrix se obtained scalar value.
  • Zero determinant: Determinant ka value 0.
  • Non-zero determinant: Determinant zero nahi hai.

1.3 Solved Example — 2×2 Determinant

Example 1 — Find the determinant
Given

A = [ [4, 7], [2, 5] ]

Find

|A|

Formula
|A| = ad − bc
Why this formula

Matrix order 2 hai. Isliye 2×2 determinant ka direct formula ad − bc applicable hai.

Substitution

a = 4, b = 7, c = 2, d = 5

Calculation

|A| = (4)(5) − (7)(2)
= 20 − 14
= 6

Answer: |A| = 6

1.4 Determinant of Order 3

Third-order determinant mein three rows aur three columns hote hain. General form:

abc
def
ghi
3×3 determinant expansion |A| = a(ei − fh) − b(di − fg) + c(dh − eg)

Is expression mein first row ke elements ke saath corresponding minors/cofactors combine hote hain. Sign pattern ko yaad rakhna important hai:

+−+

1.5 Minor and Cofactor

Minor Kisi element ka minor us row aur column ko remove karne ke baad remaining determinant hota hai.

Element aij ka minor Mij se represent kiya ja sakta hai.

Cofactor Cofactor minor ko sign factor ke saath multiply karke obtain hota hai.
Cᵢⱼ = (−1)ⁱ⁺ʲ Mᵢⱼ

Cofactor sign pattern 3×3 matrix ke liye:

+−+
−+−
+−+

1.6 Properties of Determinants

Property What happens Exam observation
Interchange of two rows Sign of determinant changes. D becomes −D.
Interchange of two columns Sign of determinant changes. D becomes −D.
Two identical rows Determinant becomes zero. D = 0.
Two identical columns Determinant becomes zero. D = 0.
One row/column all zero Determinant becomes zero. D = 0.
Multiplying one row by k Determinant is multiplied by k. New determinant = kD.
Transpose Determinant remains unchanged. |Aᵀ| = |A|.
Triangular matrix Determinant equals product of diagonal elements. Useful shortcut.
Common mistake: Row interchange ke baad determinant ka sign change karna bhoolna ek common calculation error hai.
Topic 02

Simultaneous Equations by Cramer's Rule

2.1 Basic Idea

Simultaneous equations mein multiple unknown quantities hoti hain aur sabhi equations ko ek saath satisfy karna hota hai. Unit 1 specifically three unknowns ke system ko Cramer's rule se solve karne par focus karta hai.

General system:

a₁x + b₁y + c₁z = d₁
a₂x + b₂y + c₂z = d₂
a₃x + b₃y + c₃z = d₃

2.2 Main Determinant

Coefficient determinant D = | a₁ b₁ c₁ |
| a₂ b₂ c₂ |
| a₃ b₃ c₃ |

Dx banane ke liye coefficient matrix ki first column ko constants se replace karte hain.

Dy ke liye second column replace hota hai. Dz ke liye third column replace hota hai.

Cramer's Rule x = Dₓ / D
y = Dᵧ / D
z = D𝓏 / D
Condition: Cramer's rule ke direct form mein D ≠ 0 hona chahiye. Agar D = 0 ho, to simple division by D possible nahi hoti.

2.3 Step-by-Step Method

  1. Equations ko standard form mein arrange karein.
  2. x, y aur z ke coefficients ko identify karein.
  3. Main determinant D form karein.
  4. First column ko constants se replace karke Dₓ calculate karein.
  5. Second column replace karke Dᵧ calculate karein.
  6. Third column replace karke D𝓏 calculate karein.
  7. x = Dₓ/D, y = Dᵧ/D aur z = D𝓏/D calculate karein.
  8. Final values ko original equations mein substitute karke verify karein.
Example 2 — Solve three simultaneous equations
Given

x + y + z = 6
2x − y + z = 3
x + 2y − z = 2

Find

x, y and z.

Formula
x = Dₓ/D
y = Dᵧ/D
z = D𝓏/D
Why this formula

Teen linear simultaneous equations aur teen unknowns diye gaye hain. Isliye coefficient determinant aur replacement determinants ke through Cramer's rule directly apply kiya ja sakta hai.

Calculation of D
D = | 1 1 1 |
| 2 −1 1 |
| 1 2 −1 |

D = 1[(-1)(-1) − (1)(2)]
  − 1[(2)(-1) − (1)(1)]
  + 1[(2)(2) − (-1)(1)]

= 1(1 − 2) − 1(−2 − 1) + 1(4 + 1)
= −1 + 3 + 5
= 7
Calculation of Dₓ
Dₓ = | 6 1 1 |
| 3 −1 1 |
| 2 2 −1 |

Dₓ = 6[(-1)(-1) − (1)(2)]
  − 1[(3)(-1) − (1)(2)]
  + 1[(3)(2) − (-1)(2)]

= 6(−1) − 1(−5) + 1(8)
= −6 + 5 + 8
= 7
Calculation of Dᵧ
Dᵧ = | 1 6 1 |
| 2 3 1 |
| 1 2 −1 |

Dᵧ = 1[(3)(−1) − (1)(2)]
  − 6[(2)(−1) − (1)(1)]
  + 1[(2)(2) − (3)(1)]

= −5 + 18 + 1
= 14
Calculation of D𝓏
D𝓏 = | 1 1 6 |
| 2 −1 3 |
| 1 2 2 |

D𝓏 = 1[(−1)(2) − (3)(2)]
  − 1[(2)(2) − (3)(1)]
  + 6[(2)(2) − (−1)(1)]

= −8 − 1 + 30
= 21
Answer
x = Dₓ/D = 7/7 = 1
y = Dᵧ/D = 14/7 = 2
z = D𝓏/D = 21/7 = 3
Therefore, x = 1, y = 2 and z = 3.
Verification

Equation 1: 1 + 2 + 3 = 6 ✓
Equation 2: 2(1) − 2 + 3 = 3 ✓
Equation 3: 1 + 2(2) − 3 = 2 ✓

2.4 Exam Checklist for Cramer's Rule

  • Equations ko same variable order mein likho.
  • Missing coefficient ko zero treat karo.
  • Main determinant D clearly calculate karo.
  • Replacement columns correctly identify karo.
  • Minus signs especially second-term expansion mein carefully handle karo.
  • Final values ko original equations mein verify karna useful hai.
Topic 03

Matrices — Algebra of Matrices

3.1 Definition of Matrix

Definition A matrix is a rectangular arrangement of numbers, symbols or quantities arranged in rows and columns and enclosed by brackets.

Example:

257
104

Is matrix mein 2 rows aur 3 columns hain. Therefore its order is 2 × 3.

3.2 Order of Matrix

Order Order = Number of rows × Number of columns
Matrix Order Type
[a b] 1×2 Row matrix
[a; b; c] 3×1 Column matrix
[a b; c d] 2×2 Square matrix
[a b c; d e f] 2×3 Rectangular matrix

3.3 Important Matrix Terminology

Element

Matrix ki individual entry ko element kehte hain. A ke element ko aᵢⱼ se represent kiya ja sakta hai.

Square Matrix

Jisme rows aur columns ki number equal ho, jaise 2×2 ya 3×3.

Zero Matrix

Jisme sabhi elements zero hon.

Identity Matrix

Square matrix jisme principal diagonal par 1 aur remaining positions par 0 hota hai.

3.4 Equality of Matrices

Do matrices equal tab hoti hain jab:

  1. Dono matrices ka order same ho.
  2. Corresponding elements equal hon.
A = B ⇔ corresponding elements of A and B are equal

Scalar ek single number hota hai. Scalar multiplication mein matrix ke har element ko scalar se multiply kiya jata hai.

Matrix multiplication ke liye first matrix ke columns ki number second matrix ke rows ki number ke equal honi chahiye.

Compatibility condition If A is m×n and B is n×p, then AB exists and is m×p.

Product ka individual element row × column multiplication and addition se obtain hota hai.

Transpose of a Matrix

5.1 Definition

Transpose Matrix ki rows ko columns aur columns ko rows mein interchange karne par jo matrix obtain hoti hai use transpose kehte hain.
A → Aᵀ

Agar:

123
456

To:

14
25
36

Original matrix ka order 2×3 tha aur transpose ka order 3×2 ho gaya.

5.2 Important Properties

(Aᵀ)ᵀ = A
(A+B)ᵀ = Aᵀ + Bᵀ
(A−B)ᵀ = Aᵀ − Bᵀ
(AB)ᵀ = BᵀAᵀ

Topic 06

Adjoint and Inverse of a Matrix

6.1 Adjoint — Basic Concept

Adjoint obtain karne ke liye pehle matrix ke elements ke cofactors calculate kiye jaate hain. Cofactor matrix banane ke baad uska transpose lene par adjoint obtain hota hai.

Adjoint adj(A) = (Cofactor Matrix)ᵀ

6.2 Inverse Matrix

Definition A square matrix A ka inverse A⁻¹ aisi matrix hai jiske saath multiplication karne par identity matrix obtain hoti hai.
AA⁻¹ = A⁻¹A = I

6.3 Formula for Inverse

A⁻¹ = adj(A) / |A|

Is formula ko use karne ke liye |A| ≠ 0 hona chahiye. Agar determinant zero hai, to ordinary inverse exist nahi karta.

6.4 2×2 Inverse Formula

For:

ab
cd
A⁻¹ = 1/(ad−bc) × | d −b |
| −c a |

6.5 Step-by-Step Inverse by Adjoint Method

  1. Matrix A ka determinant |A| calculate karein.
  2. Har element ka minor find karein.
  3. Minor ko sign pattern ke according cofactor mein convert karein.
  4. Cofactor matrix form karein.
  5. Cofactor matrix ka transpose lein.
  6. Is transpose ko adj(A) kehte hain.
  7. A⁻¹ = adj(A)/|A| apply karein.
  8. Result ko multiplication se verify kar sakte hain.
Example 6 — Inverse of a 2×2 Matrix
Given
21
32
Find

A⁻¹

Formula
A⁻¹ = 1/|A| × adj(A)
Determinant
|A| = (2)(2) − (1)(3)
= 4 − 3
= 1
Adjoint
adj(A) = | 2 −1 |
|−3 2 |
Substitution
A⁻¹ = 1/1 × | 2 −1 |
    |−3 2 |
A⁻¹ = [[2,−1],[−3,2]]

6.6 When Inverse Should NOT Be Used

  • Matrix square nahi hai.
  • Determinant zero hai.
  • Problem explicitly kisi different method ki demand karti hai.
  • Calculation mein inverse unnecessary complexity create kar raha ho.
Topic 07

3×3 Simultaneous Equations by Matrix Inversion Method

7.1 Matrix Form of Simultaneous Equations

Teen equations ko compact matrix form mein likha ja sakta hai:

AX = B

where:

A

Coefficient matrix.

X

Unknowns ka column matrix.

B

Constants ka column matrix.

A = | a₁ b₁ c₁ |
| a₂ b₂ c₂ |
| a₃ b₃ c₃ |

X = |x|
|y|
|z|

B = |d₁|
|d₂|
|d₃|

7.2 Derivation of Inversion Method

Starting with:

AX = B

Dono sides ko left side se A⁻¹ se multiply karein:

A⁻¹AX = A⁻¹B

Since:

A⁻¹A = I

Therefore:

IX = A⁻¹B

And:

X = A⁻¹B
Main result: Simultaneous equations ka solution matrix form mein X = A⁻¹B hota hai, provided A ka inverse exist karta ho.

7.3 Step-by-Step Procedure

  1. Given equations ko AX = B form mein convert karein.
  2. Coefficient matrix A identify karein.
  3. Constant matrix B identify karein.
  4. |A| calculate karein.
  5. Check karein ki |A| ≠ 0 hai.
  6. Adjoint method se A⁻¹ calculate karein.
  7. X = A⁻¹B calculate karein.
  8. X matrix se x, y, z ki values read karein.
  9. Original equations mein verification karein.
Example 7 — Matrix Inversion Method
Given

x + y + z = 6
2x − y + z = 3
x + 2y − z = 2

Matrix form
A = | 1 1 1 |
| 2 −1 1 |
| 1 2 −1 |

X = |x|
|y|
|z|

B = |6|
|3|
|2|
Formula
X = A⁻¹B
Important calculation

Is coefficient matrix ka determinant:

|A| = 7 ≠ 0

Therefore inverse exists. Adjoint method se A⁻¹ calculate karke B se multiply karne par:

X = |1|
|2|
|3|
Therefore x = 1, y = 2 and z = 3.

7.4 Cramer's Rule vs Matrix Inversion

Point Cramer's Rule Matrix Inversion Method
Basic idea Replacement determinants X = A⁻¹B
Main requirement D ≠ 0 for direct formula A⁻¹ must exist
Major calculation D, Dₓ, Dᵧ, D𝓏 Determinant, adjoint, inverse, multiplication
Useful for Direct equation solving Matrix-based representation

Vectors — Basic Concept

8.1 Scalar and Vector Quantities

Vector algebra samajhne ke liye scalar aur vector quantity ka difference clear hona chahiye.

Feature Scalar Vector
Magnitude Yes Yes
Direction Not required Essential characteristic
Representation Ordinary number Directed quantity / components
Examples Mass, temperature, time Displacement, velocity, force
Vector A quantity having both magnitude and direction is represented as a vector.

8.2 Geometrical Representation

Vector representation

8.3 Components of a Vector

Three-dimensional Cartesian representation mein vector ko generally x, y aur z directions ke components se express kiya ja sakta hai:

A = Aₓ i + Aᵧ j + A𝓏 k

Yahan:

  • Aₓ = x-direction component
  • Aᵧ = y-direction component
  • A𝓏 = z-direction component
  • i = x-direction unit vector
  • j = y-direction unit vector
  • k = z-direction unit vector

8.4 Magnitude of Vector

|A| = √(Aₓ² + Aᵧ² + A𝓏²)

Magnitude vector ki length ya size ko represent karti hai.

Position vector OP.

Algebra of Vectors

10.1 Vector Addition

Do vectors ko add karne ke liye corresponding components add kiye jaate hain.

A = Aₓi + Aᵧj + A𝓏k
B = Bₓi + Bᵧj + B𝓏k

A + B = (Aₓ+Bₓ)i + (Aᵧ+Bᵧ)j + (A𝓏+B𝓏)k

10.2 Vector Subtraction

A − B = (Aₓ−Bₓ)i + (Aᵧ−Bᵧ)j + (A𝓏−B𝓏)k

10.3 Scalar Multiplication of Vector

Kisi vector ko scalar k se multiply karne par vector ke har component ko k se multiply kiya jata hai.

kA = kAₓi + kAᵧj + kA𝓏k
Example 9 — Vector Addition and Subtraction
Given
A = 2i + 3j − k
B = i − 2j + 4k
Find

A+B and A−B.

Calculation
A+B = (2+1)i + (3−2)j + (−1+4)k
= 3i + j + 3k

A−B = (2−1)i + (3−(−2))j + (−1−4)k
= i + 5j − 5k

Scalar Product / Dot Product

11.1 Definition

Scalar Product Do vectors ka dot product ek scalar quantity produce karta hai.
A · B = |A||B|cosθ

Yahan:

Symbol Meaning Unit
A First vector Depends on quantity
B Second vector Depends on quantity
|A| Magnitude of A Same as A
|B| Magnitude of B Same as B

A = Aₓi + Aᵧj + A𝓏k
B = Bₓi + Bᵧj + B𝓏k

A·B = AₓBₓ + AᵧBᵧ + A𝓏B𝓏

cosθ = (A·B)/(|A||B|)

Agar two non-zero vectors perpendicular hain, θ = 90°.

cos90° = 0
Therefore A·B = 0

11.5 Parallel Vectors

Same direction mein θ = 0° hota hai:

A·B = |A||B|

Vector Product / Cross Product

Vector Product Do vectors ka cross product ek vector quantity produce karta hai jo dono original vectors ke perpendicular direction mein hota hai.
A × B = |A||B|sinθ n̂

Yahan n̂ dono vectors ke plane ke perpendicular unit vector ko indicate karta hai.

A × B = | i j k |
| Aₓ Aᵧ A𝓏 |
| Bₓ Bᵧ B𝓏 |

Expansion karte waqt first row ke signs:

+ i − j + k

12.3 Important Results

A × B = −(B × A)
A × A = 0
A × 0 = 0

12.4 Perpendicular Vectors

Agar θ = 90°:

|A×B| = |A||B|sin90° = |A||B|

12.5 Parallel Vectors

Agar θ = 0° ya 180°:

sinθ = 0
Therefore A×B = 0

B = 2i − j + k
Find

A × B

Topic 13 • IKS

Algebra in Indian Knowledge System — Simultaneous Equations

SBTE Bihar Unit 1 mein Indian Knowledge System ke under simultaneous equations ki solution approach from Indian Mathematics included hai. Is section ka purpose prescribed mathematical heritage ko algebraic problem-solving ke context mein understand karna hai.

Syllabus scope Is Unit ke IKS component ka focus simultaneous equations ko Indian Mathematics ke context mein solve karne par hai. Isliye yahan discussion isi prescribed scope tak limited rakha gaya hai.

13.1 Historical Mathematical Context

Indian mathematical tradition mein unknown quantities ko relationships aur algebraic operations ke through determine karne ki techniques develop hui hain. Engineering student ke liye important point ye hai ki mathematical notation aur modern notation different ho sakte hain, lekin underlying objective — unknown quantities ko given relationships se determine karna — same mathematical problem ko represent kar sakta hai.

13.2 Simultaneous Equation ka Basic Idea

Suppose do unknowns x aur y hain aur humein do relationships di gayi hain:

ax + by = c
px + qy = r

Dono equations ko simultaneously satisfy karne wali x aur y values desired solution hoti hain.

13.3 Elimination-Based Thinking

Simultaneous equations ko solve karne ka basic algebraic idea ye hai ki ek unknown ko eliminate karke doosre unknown ko find kiya jaaye. Uske baad obtained value ko original equation mein substitute karke remaining unknown find kiya ja sakta hai.

  1. Equations ko suitable standard form mein arrange karein.
  2. Ek variable ke coefficients ko suitable multiple se equal karein.
  3. Equations ko add/subtract karke ek variable eliminate karein.
  4. Remaining variable calculate karein.
  5. Calculated value ko original equation mein substitute karein.
  6. Final result ko check karein.
Example 12 — Two Simultaneous Equations
Given
2x + y = 7
x − y = 2
Find

x and y.

Calculation

Second equation:

x − y = 2

Therefore:

y = x − 2

First equation mein substitute:

2x + (x−2) = 7
3x − 2 = 7
3x = 9
x = 3

Therefore:

y = 3 − 2 = 1
Answer: x = 3 and y = 1.
Study note: IKS section ko sirf historical paragraph ki tarah memorize na karein. Simultaneous equations ke mathematical structure aur solution logic ko clearly samajhna important hai.

Common Mistakes

  • 2×2 determinant mein ad − bc ki jagah ad + bc likhna.
  • 3×3 determinant expansion mein signs galat karna.
  • Cramer's rule mein wrong column replace karna.
  • Matrix addition different-order matrices par perform karna.
  • Matrix multiplication ko element-by-element multiplication samajhna.
  • (AB)ᵀ = AᵀBᵀ likhna. Correct relation: (AB)ᵀ = BᵀAᵀ.
  • |A| = 0 hone par ordinary inverse apply kar dena.

Practice Zone

Exam-Oriented MCQs

1. A determinant is directly associated with which type of matrix?
A. Only row matrix
B. Only column matrix
C. Square matrix
D. Any rectangular matrix
Correct Answer: C — Determinant is defined for square matrices.
2. The determinant of [[a,b],[c,d]] is:
A. ab − cd
B. ad − bc
C. ac − bd
D. ad + bc
Correct Answer: B — The order-2 determinant is ad − bc.
3. If two rows of a determinant are identical, its value is:
A. 1
B. −1
C. Zero
D. Cannot be determined
Correct Answer: C — Identical rows make the determinant zero.
4. For Cramer's rule, the direct expressions are:
A. x=D/Dx
B. x=Dx/D
C. x=D+Dx
D. x=D−Dx
Correct Answer: B — x = Dx/D.
5. Matrix addition requires:
A. Same order
B. Same determinant
C. Same diagonal
D. Same elements only
Correct Answer: A — Matrices must have the same order for addition.
6. If A is m×n and B is n×p, the order of AB is:
A. m×p
B. n×n
C. p×m
D. m×n
Correct Answer: A — The inner dimensions n match and the outer dimensions remain m×p.
7. The transpose of a 2×3 matrix has order:
A. 2×3
B. 3×2
C. 2×2
D. 3×3
Correct Answer: B — Rows and columns interchange.
8. The inverse of A by adjoint method is:
A. A/det(A)
B. det(A)/adj(A)
C. adj(A)/det(A)
D. det(A)×adj(A)
Correct Answer: C — A⁻¹ = adj(A)/|A|, when |A| ≠ 0.
9. A matrix has an ordinary inverse only when:
A. It is rectangular
B. Its determinant is zero
C. It is square and its determinant is non-zero
D. All elements are equal
Correct Answer: C — A square matrix with non-zero determinant is non-singular and has an inverse.
10. A position vector generally starts from:
A. Any random point
B. Origin
C. End point
D. Negative axis only
Correct Answer: B — Position vector is directed from origin to the point.
11. A·B represents:
A. Vector product
B. Scalar product
C. Matrix product
D. Determinant
Correct Answer: B — Dot product is the scalar product.
12. The result of A·B is:
A. Scalar
B. Vector
C. Matrix only
D. Unit vector
Correct Answer: A — Scalar product produces a scalar.
13. The formula for scalar product is:
A. |A||B|sinθ
B. |A||B|cosθ
C. |A|/|B|
D. |A|+|B|
Correct Answer: B — A·B = |A||B|cosθ.
14. The result of A×B is:
A. Scalar
B. Vector
C. Number only
D. Determinant only
Correct Answer: B — Cross product produces a vector.
15. For perpendicular vectors A and B:
A. A·B = 0
B. A×B = 0
C. |A| = 0
D. |B| = 0
Correct Answer: A — cos90° = 0, so A·B = 0.
16. For parallel vectors A and B:
A. A×B = 0
B. A·B = 0 always
C. Both vectors become zero
D. Determinant becomes 1
Correct Answer: A — sin0° = 0, hence A×B = 0 for parallel vectors.
17. The matrix equation for a system of linear equations can be written as:
A. AX = B
B. A+B=X
C. AB=X
D. A=X+B
Correct Answer: A — The coefficient matrix form is AX = B.
18. From AX = B, multiplying by A⁻¹ gives:
A. X=A⁻¹B
B. X=AB
C. X=A+B
D. X=B⁻¹A
Correct Answer: A — A⁻¹AX = A⁻¹B and A⁻¹A = I, so X=A⁻¹B.
19. In a 3×3 cofactor sign pattern, the first row is:
A. + + +
B. − − −
C. + − +
D. − + −
Correct Answer: C — The standard cofactor sign pattern begins + − +.
20. The IKS component prescribed in Unit 1 relates to:
A. Probability distributions
B. Solution of simultaneous equations
C. Conic sections
D. Differential equations
Correct Answer: B — Unit 1 specifies solution of simultaneous equations under Indian Mathematics.
