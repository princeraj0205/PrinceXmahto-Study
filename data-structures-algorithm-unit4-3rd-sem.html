DEEP TOPIC 1

4.1 Bubble, Selection, Insertion

Bubble sort adjacent out-of-order elements swap karta hai; worst O(n²). Selection sort har pass me minimum select karke correct position par swap karta hai; O(n²). Insertion sort sorted prefix maintain karta hai aur next element ko correct position me insert karta hai; worst O(n²), but nearly sorted input par practical performance achchi hoti hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 2

4.2 Merge & Quick Sort

Merge sort array ko halves me divide karta hai, recursively sort karta hai aur sorted halves merge karta hai. Typical time O(n log n) and extra O(n) merge space. Quick sort pivot choose karke partition karta hai; average O(n log n), but poor pivot choices par worst O(n²). Partition ke baad pivot apni final relative position ke around establish hota hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 3

4.3 Linear & Binary Search

Linear search elements ko one-by-one compare karta hai; unsorted data par bhi chal sakta hai and worst O(n). Binary search sorted sequence par middle element compare karke half search space discard karta hai; worst O(log n). Har iteration me low/high update karna aur termination condition sahi rakhna important hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 4

4.4 Hash Table & Hash Function

Hash table key ko hash function se index me map karta hai. Collision tab hota hai jab do keys same slot par map hon. Direct chaining me each slot bucket/list hold kar sakta hai. Open addressing me table ke andar alternate slots search kiye jate hain. Load factor α=n/m badhne par collision probability aur probing cost badh sakti hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
