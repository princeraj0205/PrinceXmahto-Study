Unit 4 — Basics, Instruction Set and Programming of 8085

SBTE scope: evolution, 8085 architecture/pin diagram, timing/memory organization, interrupts, instruction categories, addressing modes and assembly-language programming. fileciteturn307file8

8085 Architecture

8085 is an 8-bit microprocessor. Its major blocks include ALU, accumulator, general-purpose registers, program counter, stack pointer, instruction register/decoder, timing/control unit and interrupt/control logic. The 16-bit address capability allows addressing of a 64-KB memory space.

Timing & Memory

Instruction execution is divided into machine cycles and T-states. Address and data transfer occur through the processor's buses; the timing diagram shows when address, control and data signals are valid.

Interrupts

Interrupts allow external/internal events to request processor attention. 8085 has hardware interrupt inputs with different priorities/triggering characteristics; exam answers should identify the interrupt name and its basic role.

Instruction Set

  • Data transfer: MOV, MVI, LXI etc.
  • Arithmetic: ADD, ADC, SUB, INR, DCR etc.
  • Logical: ANA, ORA, XRA, CMP etc.
  • Branching: JMP, conditional jumps, CALL, RET.
  • Control: NOP, HLT and related control operations.

Addressing Modes

Immediate: operand is part of instruction. Register: operand in register. Direct: memory address explicitly supplied. Indirect: register pair contains memory address. Indexed: effective address formed using an index mechanism; use the terminology expected by the syllabus/instruction set context.

Assembly Programming

Typical program-writing workflow: define objective → identify registers/memory → choose instructions → trace flags/registers → terminate with HLT or appropriate control. Practice addition, subtraction, data transfer, comparisons and simple loops.

Exam focusArchitecture block diagram, pin functions, timing diagram, interrupts, instruction classification, five addressing modes and short ALPs.
