1. 8085 Basics & Architecture

8085 is an 8-bit microprocessor with 16-bit address capability, allowing up to 64 KB addressable memory space. Major blocks: ALU, accumulator, general-purpose registers, flags, program counter, stack pointer, instruction register/decoder, timing-control unit and interrupt logic.

BlockFunction
ALUArithmetic and logical operations
AccumulatorImportant operand/result register
PCAddress of next instruction
SPStack pointer
FlagsStatus conditions such as Zero, Sign, Carry
Control unitTiming/control signals

2. Pin, Bus & Timing

8085 system me address, data and control/status signals work together. Instruction execution machine cycles aur T-states me organized hota hai. Timing diagram me address/data validity aur control signals ko correct sequence me label karna exam skill hai.

3. Memory Organization & Interrupts

16-bit address capability means 2¹⁶ = 65536 addressable locations. Interrupt processor ko service request deta hai; hardware interrupt inputs ki priority/behavior different ho sakti hai. Exam me interrupt name, purpose and relevant priority/triggering property likho.

4. Instruction Set

CategoryExamples
Data transferMOV, MVI, LXI
ArithmeticADD, ADC, SUB, INR, DCR
LogicalANA, ORA, XRA, CMP
BranchingJMP, conditional jump, CALL, RET
ControlNOP, HLT

5. Addressing Modes

  • Immediate: operand instruction me, e.g. MVI A,32H.
  • Register: operand register me, e.g. MOV A,B.
  • Direct: memory address explicitly given, e.g. LDA 2050H.
  • Indirect: register pair memory address hold karta hai.
  • Indexed: index-based effective-address concept; course-specific examples follow karo.

6. Assembly Language Programming

Example: 2050H aur 2051H par stored two 8-bit numbers add karke 2052H par result store:

LDA 2050H MOV B,A LDA 2051H ADD B STA 2052H HLT

Carry case me Carry flag ko test/store karne ke liye appropriate branch/store instructions add kiye ja sakte hain. Subtraction program me minuend/subtrahend load karke suitable subtraction sequence aur result storage likho.
