4.1 Basic Memory Management: Partitioning

Memory management ka aim processes ko memory provide karna, protection maintain karna aur available memory ko efficiently use karna hai.

Fixed Partitioning

Main memory ko predefined fixed-size partitions mein divide kiya jata hai. Ek partition mein ek process place kiya ja sakta hai. Process partition se chhota ho to unused space internal fragmentation create kar sakta hai.

Variable Partitioning

Process ki requirement ke according partition allocate kiya jata hai. Isse fixed-size waste kam ho sakta hai, lekin free spaces ke beech gaps/external fragmentation develop ho sakti hai.

Free-Space Management

Bitmap: memory/storage units ko bits se represent kiya ja sakta hai; bit allocated/free status indicate karti hai. Linked list: free blocks/holes ko linked records ke through track kiya jata hai.

4.2 Virtual Memory, Paging, Segmentation, Fragmentation & Page Fault

Virtual memory process ko aisa logical address-space experience deti hai jo available physical memory se larger ho sakta hai; OS required portions ko memory mein laata hai aur non-required portions ko backing storage par rakh sakta hai.

Paging: logical memory ko fixed-size pages aur physical memory ko fixed-size frames mein divide kiya jata hai. Page table logical page ko physical frame se map karti hai.

Logical address = [Page number | Offset] Physical address = [Frame number | Offset]

Segmentation: program ko logical variable-size segments, jaise code, data ya stack, ke form mein view karta hai. Segment table mapping information rakhti hai.

Fragmentation: internal fragmentation allocated block ke andar unused space se associated hai; external fragmentation available free space ke scattered holes se associated hai.

Page fault: required page physical memory mein present nahi milta, to OS ko page ko backing storage se fetch karke memory mein load karna padta hai, phir execution continue hota hai.

4.3 Page Replacement Algorithms

AlgorithmRuleExam calculation
FIFOSabse purana loaded page replace.Queue/order maintain karo.
LRULeast recently used page replace.Past reference history track karo.
OptimalFuture mein sabse late use hone wala page replace.Reference string ka future dekh kar choice.

Page-fault numerical steps: frames initially empty lo → reference string left-to-right process karo → hit ho to page fault nahi → miss ho to empty frame use karo, otherwise selected replacement policy apply karo → total page faults count karo.

Optimal algorithm future references ko use karta hai, isliye practical systems mein future knowledge unavailable hone ke karan ise comparison/benchmarking reference ke roop mein samjha jata hai.
