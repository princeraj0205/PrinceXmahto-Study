Practical 1: Types of Operating Systems

Aim: To prepare a report describing the features of different types of operating systems with examples.

Introduction: An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages the CPU, memory, files, input/output devices, processes and security.

1. Batch Operating System

Collects similar jobs and processes them in batches without continuous user interaction. It offers automatic job sequencing and reduced manual intervention, but turnaround time can be long. Example: early IBM mainframe batch systems.

2. Multiprogramming Operating System

Keeps several programs in main memory. When one program waits for input/output, the CPU can execute another, improving CPU utilization and throughput. Examples include early UNIX and mainframe systems.

3. Time-Sharing Operating System

Divides CPU time into small time slices, giving interactive users or processes a turn. It provides quick response and supports concurrent users. Examples: UNIX and Linux multi-user systems.

4. Multiprocessing Operating System

Uses two or more processors or CPU cores to execute tasks. It can improve throughput and responsiveness. Examples: modern Windows, Linux and macOS on multi-core computers.

5. Real-Time Operating System (RTOS)

Designed to respond to events within defined time limits. Hard real-time systems must meet critical deadlines; soft real-time systems allow occasional misses. Examples: FreeRTOS and QNX.

6. Mobile Operating System

Designed for phones and tablets, managing touch input, wireless communication, sensors, battery use, apps and permissions. Examples: Android and iOS.

Comparison

  • Batch: jobs in groups; good for repetitive work; mainframe batch systems.
  • Multiprogramming: several programs in memory; high CPU utilization; UNIX-like systems.
  • Time-sharing: CPU time slices; interactive response; UNIX/Linux.
  • Multiprocessing: multiple CPUs/cores; parallel execution; Windows/Linux.
  • Real-time: deadline-based response; predictable timing; FreeRTOS/QNX.
  • Mobile: phone/tablet features; power and sensor management; Android/iOS.
