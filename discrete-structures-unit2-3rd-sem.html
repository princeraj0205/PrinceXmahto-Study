2.1 Sets and Subsets

A set is a well-defined collection of distinct objects. If every element of A is also in B, then A⊆B. Power set P(A) contains all subsets of A; for |A|=n, |P(A)|=2ⁿ.

2.2 Operations

Union A∪B collects elements from either set; intersection A∩B contains common elements; difference A−B contains elements in A but not B; complement A′ depends on the universal set. Cartesian product A×B contains ordered pairs (a,b).

De Morgan's laws(A∪B)′ = A′∩B′ and (A∩B)′ = A′∪B′.

2.3 Venn Diagrams

Use circles inside a universal rectangle to visually represent membership. For numerical set problems, first write the known regions, then use union/intersection totals to find unknown regions.

2.4 Relations

A relation R from A to B is a subset of A×B. The domain is the set of first components appearing in R; the range is the set of second components appearing.

Important properties on a set: reflexive (aRa for every a), symmetric (aRb ⇒ bRa), antisymmetric (aRb and bRa ⇒ a=b), and transitive (aRb and bRc ⇒ aRc).

2.5 Equivalence Relation

A relation that is reflexive, symmetric and transitive is an equivalence relation. It partitions a set into equivalence classes. In exams, verify the three properties one by one rather than declaring it directly.

Quick Revision

Set → subset/power set → union/intersection/difference/complement → Venn → relation/domain/range → properties → equivalence relation.

Unit 2 — Set Theory & Relations

Set operations, Venn diagrams, relation properties and equivalence relations.

2.1 Sets & Subsets

Set well-defined distinct objects ka collection hai. Roster aur set-builder notation use hoti hai. A⊆B means every element of A is in B; proper subset A⊂B additionally A≠B.

2.2 Set Operations

Union A∪B, intersection A∩B, difference A−B and complement A′. Universal set U ke relative complement define hota hai.

2.3 Venn Diagrams

Rectangle U aur circles sets ko represent karte hain. Operations ko visual form me verify karne ke liye useful.

2.4 De Morgan Laws

(A∪B)′=A′∩B′    (A∩B)′=A′∪B′

Element method me arbitrary x lo aur membership statements ko logical equivalence se transform karo.

2.5 Relations

R from A to B is a subset of A×B. Ordered pairs relation membership show karte hain. Domain = first components; range = second components occurring in R.

2.6 Relation Properties

  • Reflexive: aRa.
  • Symmetric: aRb⇒bRa.
  • Antisymmetric: aRb and bRa⇒a=b.
  • Transitive: aRb and bRc⇒aRc.

2.7 Equivalence Relation

Reflexive + symmetric + transitive relation equivalence relation hai. It partitions a set into equivalence classes.

2.8 Worked Example

Integers par aRb iff a−b even: reflexive because 0 even; symmetric because sign change keeps even; transitive because sum of even numbers is even.
