1.1 Python Character Set, Tokens, Variables, L-value/R-value and Comments

Python Character Set

The character set is the collection of characters that can occur in Python source code. Python programs commonly use letters, digits, whitespace, operators, punctuation symbols and characters inside string literals.

CategoryExamplesUse
LettersA-Z, a-zIdentifiers, keywords and text
Digits0-9Numbers and identifiers after the first character
Whitespacespace, tab, newlineSeparation and indentation
Special symbols+ - * / = ( ) [ ] { } , : .Operators, grouping, collections and syntax
String characters"Hello", 'Python'Represent text

Python Tokens

A token is a meaningful lexical unit of source code. In simple terms, tokens are the small pieces from which Python statements are formed.

Token typeExampleExplanation
Keywordif, else, TrueReserved words with predefined meaning.
Identifiermarks, student_nameName given by the programmer.
Literal25, 3.14, "CSE"Fixed value written directly in code.
Operator+, ==, andPerforms or expresses an operation.
Delimiter( ), [ ], :, ,Helps define structure.
Common mistake Python is case-sensitive. marks, Marks and MARKS are different identifiers.

Variables

A variable is a name used to refer to a value. In Python, assignment creates or rebinds a variable name.

name = "Prince"
age = 18
percentage = 82.5

Here, name, age and percentage are variable names. Python determines the type from the value assigned at runtime.

Identifier rules

  • Use letters, digits and underscore.
  • The first character cannot be a digit.
  • Do not use a Python keyword as an identifier.
  • Use meaningful names such as total_marks rather than unclear names.
  • Identifiers are case-sensitive.

L-value and R-value

The syllabus specifically includes L value and R value concepts. fileciteturn6file0

The L-value is the location/name that receives a value during an assignment. The R-value is the value or expression being assigned.

total = marks + bonus

total is the assignment target (L-value position), while marks + bonus produces the value (R-value).

Remember In an assignment statement, the left side identifies where the result is stored/rebound and the right side provides the value to be assigned.

Comments

Comments are notes for humans and are ignored as executable Python statements.

# This is a single-line comment
marks = 85  # Store the marks

Comments improve readability and help document program logic.

marks = 72

Sequence Types

String

A string represents text. It is written using quotes.

name = "Prince Raj"
print(name)
print(name[0])

Strings support indexing and several operations; detailed string operations belong to Unit 3 in the uploaded syllabus, so this Unit 1 note limits discussion to the data-type foundation.

List

A list stores an ordered collection of values and can contain different data types.

marks = [78, 85, 91]
print(marks)

Tuple

A tuple stores an ordered collection of values and is written using parentheses.

point = (10, 20)
print(point)

None Type

None represents the absence of a value. It is different from 0, False and an empty string.

result = None
print(result)

Mapping Type — Dictionary

A dictionary stores data as key-value pairs.

student = {
    "name": "Prince",
    "semester": 3
}
print(student["name"])
Prince

Mutable vs Immutable Data Types

Mutable objects can be changed after creation. Immutable objects cannot be changed in place after creation.

ConceptTypical examplesMeaning
MutableList, Dictionary, SetContents can be changed after creation.
ImmutableInteger, Float, Boolean, String, Tuple, NoneThe object’s value cannot be changed in place.
Example A list can be modified with an item assignment such as marks[0] = 90. A string cannot be modified character-by-character in place; a new string value must be produced.

Assignment and Augmented Assignment Operators

x = 10
x += 5   # x becomes 15
x -= 2   # x becomes 13
x *= 2   # x becomes 26
x /= 2   # x becomes 13.0

Augmented assignment combines an operation with assignment. It makes repeated updates shorter and clearer.

Expressions and Statements

An expression is a combination of values, variables, operators and function calls that produces a value.

total = price * quantity

The part price * quantity is an expression. An assignment statement uses its result to update total.

Exam distinction An expression evaluates to a value; a statement is a complete instruction executed by the program.

Type Conversion

Type conversion changes a value from one data type to another when the conversion is valid.

age_text = "18"
age = int(age_text)

price = "99.50"
amount = float(price)

number = 25
text = str(number)
FunctionCommon use
int()Convert to integer where valid.
float()Convert to floating-point value.
str()Convert a value to text representation.
bool()Convert a value to Boolean.

Input and Output Mechanisms

input() reads user input and returns it as text. Convert it when a numerical value is required.

name = input("Enter your name: ")
age = int(input("Enter your age: "))

print("Name:", name)
print("Age:", age)
Common mistake input() returns a string. Writing age = input(...) and then expecting age + 1 to perform numerical addition will cause a type problem unless the input is converted with int().

Precedence of Operators

When an expression contains several operators, Python follows precedence rules to determine which operation is evaluated first. Parentheses can be used to make the intended order explicit.

result = 2 + 3 * 4
print(result)          # 14

result2 = (2 + 3) * 4
print(result2)         # 20

Program 1 — Area of a Triangle Using Three Sides

Problem

Given sides a, b and c, calculate the area using Heron's formula.

Logic

First calculate s=(a+b+c)/2. Then calculate Area = √(s(s-a)(s-b)(s-c)).

Algorithm

  1. Read a, b, c.
  2. Calculate semi-perimeter s.
  3. Calculate the expression inside the square root.
  4. Calculate and display the area.
import math

a = float(input("Enter side a: "))
b = float(input("Enter side b: "))
c = float(input("Enter side c: "))

s = (a + b + c) / 2
area = math.sqrt(s * (s-a) * (s-b) * (s-c))

print("Area =", area)

Sample output

Enter side a: 3
Enter side b: 4
Enter side c: 5
Area = 6.0
Common error Heron's formula requires valid triangle sides. For the 3-4-5 example, the expression is valid and gives an area of 6 square units.

Program 3 — Solve a Quadratic Equation for Real Roots

For ax² + bx + c = 0, calculate the discriminant D=b²-4ac. Real roots exist when D ≥ 0.

import math

a = float(input("Enter a: "))
b = float(input("Enter b: "))
c = float(input("Enter c: "))

D = b*b - 4*a*c

if D >= 0:
    root1 = (-b + math.sqrt(D)) / (2*a)
    root2 = (-b - math.sqrt(D)) / (2*a)
    print("Root 1 =", root1)
    print("Root 2 =", root2)
else:
    print("No real roots")
Exam Tip Always check the discriminant before taking its square root when the question asks specifically for real roots.
