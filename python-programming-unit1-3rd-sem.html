1.1 Python Character Set, Tokens, Variables, L-value/R-value and Comments

Python Character Set

The character set is the collection of characters that can occur in Python source code. Python programs commonly use letters, digits, whitespace, operators, punctuation symbols and characters inside string literals.

Python Tokens

A token is a meaningful lexical unit of source code. In simple terms, tokens are the small pieces from which Python statements are formed.

Token typeExampleExplanation
Keywordif, else, TrueReserved words with predefined meaning.
Identifiermarks, student_nameName given by the programmer.
Literal25, 3.14, "CSE"Fixed value written directly in code.

Common mistake Python is case-sensitive. marks, Marks and MARKS are different identifiers.

Variables

A variable is a name used to refer to a value. In Python, assignment creates or rebinds a variable name.

name = "Prince"
age = 18
percentage = 82.5

Here, name, age and percentage are variable names. Python determines the type from the value assigned at runtime.

Identifier rules

  • Use letters, digits and underscore.
  • The first character cannot be a digit.
  • Do not use a Python keyword as an identifier.
  • Use meaningful names such as total_marks rather than unclear names.
  • Identifiers are case-sensitive.

L-value and R-value

The syllabus specifically includes L value and R value concepts. fileciteturn6file0

The L-value is the location/name that receives a value during an assignment. The R-value is the value or expression being assigned.

total = marks + bonus

total is the assignment target (L-value position), while marks + bonus produces the value (R-value).

Remember In an assignment statement, the left side identifies where the result is stored/rebound and the right side provides the value to be assigned.

Comments

Comments are notes for humans and are ignored as executable Python statements.

# This is a single-line comment
marks = 85  # Store the marks

Comments improve readability and help document program logic.

Expressions and Statements

An expression is a combination of values, variables, operators and function calls that produces a value.

total = price * quantity

The part price * quantity is an expression. An assignment statement uses its result to update total.

Exam distinction An expression evaluates to a value; a statement is a complete instruction executed by the program.

Program 1 — Area of a Triangle Using Three Sides

Problem

Given sides a, b and c, calculate the area using Heron's formula.

Logic

First calculate s=(a+b+c)/2. Then calculate Area = √(s(s-a)(s-b)(s-c)).

Algorithm

  1. Read a, b, c.
  2. Calculate semi-perimeter s.
  3. Calculate the expression inside the square root.
  4. Calculate and display the area.
import math

a = float(input("Enter side a: "))
b = float(input("Enter side b: "))
c = float(input("Enter side c: "))

s = (a + b + c) / 2
area = math.sqrt(s * (s-a) * (s-b) * (s-c))

print("Area =", area)

Sample output

Enter side a: 3
Enter side b: 4
Enter side c: 5
Area = 6.0
Common error Heron's formula requires valid triangle sides. For the 3-4-5 example, the expression is valid and gives an area of 6 square units.

Program 2 — Swap Two Variables

a = 10
b = 20

a, b = b, a

print("a =", a)
print("b =", b)
a = 20
b = 10

Python's multiple assignment allows the two values to be exchanged directly.

Program 3 — Solve a Quadratic Equation for Real Roots

For ax² + bx + c = 0, calculate the discriminant D=b²-4ac. Real roots exist when D ≥ 0.

import math

a = float(input("Enter a: "))
b = float(input("Enter b: "))
c = float(input("Enter c: "))

D = b*b - 4*a*c

if D >= 0:
    root1 = (-b + math.sqrt(D)) / (2*a)
    root2 = (-b - math.sqrt(D)) / (2*a)
    print("Root 1 =", root1)
    print("Root 2 =", root2)
else:
    print("No real roots")
Exam Tip Always check the discriminant before taking its square root when the question asks specifically for real roots.

Detailed Theory Notes — Book Level Explanation

This section expands the same Unit 1 syllabus into classroom-style theory. The purpose is not to replace the syllabus, but to explain each listed concept from the ground up with definitions, reasoning, examples, common mistakes and exam-ready points.

1. Why Python is used

Python is a high-level, general-purpose programming language. A high-level language lets the programmer express a solution using concepts that are easier for humans to read than machine-level instructions. Python is also designed with a concise syntax, so a beginner can concentrate on problem-solving instead of writing a large amount of boilerplate code.

Python is used in many areas such as scripting, web development, automation, data processing, scientific computing and machine learning. The SBTE syllabus introduces Python 3 as the foundation for later topics such as control statements, sequence operations, functions, NumPy, exceptions and file handling. The uploaded course rationale describes Python as a high-level general-purpose language and notes its use across a wide range of application areas. fileciteturn24file3

2. Source code, interpretation and execution — basic idea

A Python program is first written as source code. When the program is executed, Python processes that source and performs the instructions. For a beginner, the important point is that the text written in the editor must follow Python's syntax rules.

Write source code→Python processes code→Expressions are evaluated→Output / result

For example:

length = 10
width = 5
area = length * width
print(area)

The names length and width refer to values, length * width is an expression, the assignment updates area, and print() displays the result.

3. Syntax, semantics and errors

Syntax means the grammatical rules of the language. A syntax error occurs when code does not follow those rules. Semantics is the meaning of a valid statement. A program may be syntactically valid but still produce an unwanted result because its logic or data is incorrect.

TypeSimple meaningExample
Syntax errorCode violates Python grammar.Missing closing parenthesis.
Runtime errorProblem occurs while execution is taking place.Dividing by zero.
Logical errorProgram runs but gives an incorrect result.Using addition where multiplication was required.
Exam point Unit 1 mainly builds the syntax foundation. Understanding syntax helps you write valid expressions and statements before moving to conditional and iterative statements in Unit 2.

4. Keywords and identifiers — detailed understanding

Keywords are reserved words that already have a special meaning in Python. They are not intended to be used as ordinary variable names. Examples include if, else, for, while, True, False, None, and, or and not.

Identifiers are names created by the programmer for variables and other program entities. Good identifiers communicate purpose.

# Good names
student_name = "Prince"
total_marks = 450
average_marks = total_marks / 5

# Legal but less descriptive
x = 450

A good naming style makes a program easier to read, debug and maintain. The name should indicate what the value represents.

5. Literals

A literal is a value written directly in source code. Common Unit 1 examples include integer literals, floating-point literals, complex literals, Boolean literals and string literals.

LiteralExample

6. Whitespace and indentation

Whitespace can separate tokens, and indentation is especially important in Python because indentation is used to show the structure of blocks. Although detailed decision and loop blocks belong to Unit 2, students should understand the principle from Unit 1.

marks = 75
if marks >= 40:
    print("Pass")

The indented line belongs to the if block. Consistent indentation is therefore part of writing correct Python programs.

7. Assignment is not mathematical equality

In Python, = is the assignment operator. It means that the result of the right-hand expression is assigned to the name on the left. It is different from ==, which compares two values.

x = 10       # assignment
print(x == 10) # comparison → True
Very common exam mistake Do not write x == 10 when you mean to assign 10 to x. Use x = 10.

8. Dynamic typing — basic concept

Python variable names are not permanently declared with a single data type in the way beginners may have seen in some statically typed languages. A name can refer to a value of one type and later be rebound to a value of another type.

x = 10
print(type(x))

x = "Python"
print(type(x))

The variable name remains x, but the value it refers to has changed from an integer to a string. This is one reason Python code can be concise, but it also means the programmer must pay attention to the type of the current value.

9. The type() function

type() is useful for examining the type of a value while learning and debugging.

a = 25
b = 4.5
c = "CSE"
d = True
e = [1, 2, 3]

print(type(a))
print(type(b))
print(type(c))
print(type(d))
print(type(e))

Using type() is especially helpful when an expression is not behaving as expected because the input may have a different type from what you assumed.

10. Integer, float and complex — deeper comparison

An integer represents whole-number values. A floating-point value represents a number with a fractional component. A complex number has a real part and an imaginary part and uses j for the imaginary component.

i = 10
f = 10.0
z = 10 + 2j

print(i)
print(f)
print(z)
print(z.real)
print(z.imag)

Notice that 10 and 10.0 are numerically similar in ordinary arithmetic but belong to different types.

11. Boolean values in expressions

Boolean values are essential because comparisons produce them and logical operators combine them.

age = 18
print(age >= 18)
print(age < 18)

The results are True and False. These Boolean results later become the basis for decision making in Unit 2.

12. String as a sequence type — foundation

A string is an ordered sequence of characters. Because characters have positions, an individual character can be accessed by an index.

word = "PYTHON"
print(word[0])
print(word[1])
print(word[-1])

The detailed operations on strings, including concatenation, repetition, membership, slicing and traversal, are explicitly covered in Unit 3 of the uploaded syllabus. Therefore, for Unit 1, remember the definition and basic nature of string as a sequence type. fileciteturn24file0

13. List as a sequence type

A list is an ordered collection. Lists are mutable, which means their contents can be changed after the list is created.

subjects = ["Python", "OS", "DSA"]
subjects[0] = "Python Programming"
print(subjects)

The ability to modify list contents is the key Unit 1 connection with the concept of mutability.

14. Tuple as a sequence type

A tuple is also ordered, but it is immutable. A tuple is suitable for representing a fixed group of values.

coordinates = (25.5, 85.1)
print(coordinates[0])

The tuple can be read, but an element cannot be replaced in place using ordinary item assignment.

15. Dictionary — key-value model

A dictionary represents information through keys and associated values. Instead of accessing a value by a numeric position like a list, a program normally accesses a dictionary value through its key.

student = {
    "name": "Prince",
    "branch": "CSE",
    "semester": 3
}

print(student["branch"])

Here, "branch" is a key and "CSE" is its associated value.

16. None is not zero

None is a special value used to indicate that there is no meaningful value at that point. It should not be treated as the number zero.

ValueBasic idea
0Integer value zero.
FalseBoolean false value.
""Empty string.
[]Empty list.
NoneNo value / absence of a value.

17. Mutability — what actually changes?

When we say an object is mutable, we mean the object itself can be modified without replacing it with a different object value. For example, a list can have one of its elements changed.

numbers = [10, 20, 30]
numbers[1] = 99
print(numbers)

The list now contains 99 at the second position. Strings, in contrast, are immutable:

word = "cat"
# word[0] = "b"   # invalid: string cannot be changed this way
word = "bat"      # a new string value is assigned to the name
Easy memory trick Mutable means “can be modified”; immutable means “cannot be modified in place.”

18. Arithmetic operators — practical interpretation

Arithmetic operators form numerical expressions. The result type can depend on the operation and operand values.

a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.333...
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000

/ is ordinary division, while // performs floor division. % gives the remainder, which is particularly useful in problems involving divisibility.

19. Relational operators — comparison produces Boolean

a = 10
b = 20

print(a == b)
print(a != b)
print(a < b)
print(a > b)
print(a <= b)
print(a >= b)

Every comparison should be understood as a question whose answer is a Boolean value. This idea becomes important when writing conditions.

20. Logical operators — combining conditions

age = 20
has_id = True

print(age >= 18 and has_id)
print(age < 18 or has_id)
print(not has_id)

and combines conditions so that both conditions must be true for the combined logical condition to be true. or requires at least one true condition. not reverses the Boolean result.

21. Assignment operators — step by step

x = 10
x += 5   # equivalent in value effect to x = x + 5
x -= 3   # x = x - 3
x *= 2   # x = x * 2
x /= 2   # x = x / 2

Augmented assignment is convenient when a variable is repeatedly updated. Similar operators include //=, %= and **=.

Consider:

The expression a + b produces the value 15. The complete line c = a + b is an assignment statement that tells Python to bind that result to c.

23. Explicit and implicit type conversion

Explicit conversion is performed deliberately using conversion functions such as int(), float() and str(). Some operations also involve automatic numeric type handling.

x = "25"
n = int(x)

a = 5
b = 2.5
result = a + b
print(result)

In the second example, the arithmetic involves an integer and a floating-point value and the result is suitable for the combined numeric operation.

24. Input → Convert → Process → Output

A very common beginner program follows this four-stage pattern:

Input→Conversion→Processing→Output
length = float(input("Enter length: "))
width = float(input("Enter width: "))

area = length * width

print("Area =", area)

This pattern is extremely useful for practical examinations because many programs are simply variations of input, conversion, calculation and display.

25. print() — output basics

The print() function displays values.

name = "Prince"
age = 18

print(name)
print(age)
print("Name:", name, "Age:", age)

Multiple values can be supplied to print(). Keeping output labels clear makes practical programs easier to understand.

26. Operator precedence — how to solve questions

When an exam asks you to evaluate an expression, do not calculate from left to right blindly. First identify parentheses, then higher-precedence operations, and then lower-precedence operations.

value = 5 + 2 * 3 ** 2
  1. Power: 3 ** 2 = 9
  2. Multiplication: 2 * 9 = 18
  3. Addition: 5 + 18 = 23

Therefore the final value is 23.

27. Parentheses improve clarity

Even when Python's precedence rules are known, parentheses are useful because they make the intended logic obvious to a reader.

average = total / count
percentage = (obtained / maximum) * 100

In educational programs, clear parentheses can make your answer easier to inspect and reduce mistakes.

32. Model long-answer: Explain Python data types

Answer: A data type specifies the kind of value represented by an object. In Unit 1, the syllabus covers number types, Boolean, sequence types, None and dictionary. Number types include integer, floating point and complex. Boolean represents True or False. String, list and tuple are sequence types. None represents absence of a value. Dictionary represents key-value data. The syllabus also asks students to distinguish mutable and immutable data types. Lists and dictionaries are commonly used as mutable structures, while strings, tuples and numeric values are treated as immutable. fileciteturn24file0

33. Model long-answer: Explain operators

Answer: Operators are symbols or keywords used to perform operations or express relationships. Arithmetic operators perform numerical calculations; relational operators compare values; logical operators combine logical conditions; assignment operators assign values; and augmented assignment operators combine an operation with assignment. Expressions are formed by combining values, variables and operators. Python evaluates expressions according to operator precedence, while parentheses can be used to specify the desired grouping.

34. Model long-answer: Explain L-value and R-value

Answer: In an assignment such as total = price * quantity, the left side identifies the target that receives the result, while the right side contains the expression whose value is calculated. Thus, total is the L-value position and price * quantity is the R-value expression. Understanding this distinction helps students read assignment statements correctly.
