Unit 6 — Exception and File Handling

SBTE scope: syntax errors/exceptions, user-defined exceptions, raise/catch, try-except-else, try-finally, built-in exception classes; text/binary files, open/close, read/write and access modes. fileciteturn308file1

Exception Handling

A syntax error prevents valid parsing; an exception occurs during execution. try contains risky code, except handles selected exceptions, else runs when no exception occurs, and finally runs for cleanup regardless of success/failure.

try: x = int(input()) print(10/x) except ZeroDivisionError: print("Cannot divide by zero") except ValueError: print("Enter a number") finally: print("Done")

raise explicitly creates an exception. User-defined exceptions can be created by defining a class derived from an exception class. Common built-ins in the syllabus/practical list include TypeError, NameError, IndexError, KeyError, ValueError, IOError and ZeroDivisionError. fileciteturn308file7

File Handling

Text files store character data; binary files store bytes. open() creates a file object and the mode determines the operation. Common modes include r (read), w (write/truncate/create), a (append) and their binary variants such as rb/wb. Always close files or use a context manager.

with open("notes.txt","r") as f: data = f.read() with open("out.txt","a") as f: f.write("Hello\n")
