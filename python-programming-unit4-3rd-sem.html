4.1 Function kya hota hai?

Function code ka ek named block hota hai jo ek particular task perform karta hai. Ek baar function define karne ke baad usse baar-baar call kiya ja sakta hai.

def greet():
    print("Hello Prince")

greet()
greet()

Yahan greet() function do baar call hua, isliye same task do baar perform hua.

Define→Function name→Call→Execute→Result

Function ki need kyun?

  • Reusability: same logic ko repeatedly use kar sakte ho.
  • Modularity: large program ko small logical parts mein divide karte hain.
  • Readability: code samajhna easy hota hai.
  • Testing: individual function ko separately test kar sakte ho.
  • Maintenance: ek function mein change karke related calls ko benefit mil sakta hai.

User Defined Function banana

Python mein user-defined function banane ke liye def keyword use hota hai.

def add(a, b):
    result = a + b
    return result

answer = add(10, 20)
print(answer)

Syntax

def function_name(parameters):
    statements
    return value

def function definition start karta hai. Function name ke baad parentheses mein parameters aa sakte hain. Colon ke baad indented body hoti hai.

Arguments aur Parameters

Parameter function definition mein receive hone wala variable hai. Argument function call ke time pass ki gayi actual value hai.

def square(n):       # n = parameter
    return n * n

print(square(5))     # 5 = argument
Exam line: Parameter = function definition ka variable; Argument = function call par di gayi actual value.

Positional Parameters / Arguments

Positional passing mein values ka meaning unki position se decide hota hai.

def student(name, age):
    print(name, age)

student("Prince", 18)

Yahan first argument name aur second argument age ko milta hai.

Default Parameters

Default parameter ko pehle se ek default value di ja sakti hai. Agar call mein value pass nahi ki gayi to default value use hoti hai.

def greet(name="Student"):
    print("Hello", name)

greet("Prince")
greet()

First call mein Prince print hoga aur second call mein Student.

Important: Default parameter ko usually required non-default parameter ke baad rakhna chahiye.

Multiple Parameters

def calculate(a, b, c):
    return a + b + c

print(calculate(10, 20, 30))

Lambda Functions

Lambda ek small anonymous function hota hai. Iska use short expression-based calculation ke liye kiya ja sakta hai.

square = lambda x: x * x

print(square(6))

Yahan lambda ek input x leta hai aur x*x return karta hai.

Normal functionLambda
def keywordlambda keyword
Multiple statements possibleGenerally one expression
Named function commonlyAnonymous/short function commonly

Returning a Value

return function se result caller ko wapas bhejta hai.

def multiply(a, b):
    return a * b

result = multiply(7, 8)
print("Result =", result)

Agar function mein explicit return nahi hai, to function normally None return karta hai.

Return vs print

print()return
Screen par output display karta hai.Value caller ko wapas deta hai.
Result ko directly calculation mein reuse nahi karta.Returned value ko variable mein store/reuse kar sakte hain.

Variable Scope — Local aur Global

Scope batata hai ki variable ko program ke kis part mein access kiya ja sakta hai.

Local Scope

Function ke andar banaya variable generally us function ka local variable hota hai.

def show():
    x = 10
    print(x)

show()
# print(x)  # NameError

Global Scope

Function ke bahar define variable global scope mein hota hai aur function ke andar read kiya ja sakta hai.

x = 100

def show():
    print(x)

show()

global keyword

Agar function ke andar global variable ko modify karna ho, to global keyword use kiya ja sakta hai.

x = 10

def change():
    global x
    x = 50

change()
print(x)
Exam point: Local variable ka scope function ke andar hota hai; global variable ka scope wider hota hai. Global variable ko function ke andar modify karne ke liye global keyword relevant hai.

Scope example — same name

x = 100

def demo():
    x = 20
    print("Inside:", x)

demo()
print("Outside:", x)

Output mein inside 20 aur outside 100 hoga, kyunki function ke andar ka x local hai.

4.2 Modules and Packages

Module ek Python file hoti hai jisme functions, variables aur other Python definitions ho sakti hain. Module ka main benefit code organization aur reuse hai.

Simple custom module

Maan lo same folder mein calc.py file hai:

def add(a, b):
    return a + b

def square(x):
    return x * x

Dusri file se ise import:

import calc

print(calc.add(10, 20))
print(calc.square(5))

Importing module using import

import math

print(math.sqrt(25))
print(math.pi)

import math ke baad module ke members ko generally math.member format mein access karte hain.

Specific function import karna

from math import sqrt

print(sqrt(81))

Is form mein poora module name har call par likhna zaroori nahi hota.

Alias

import math as m

print(m.sqrt(49))

as se module ka short alias bana sakte hain.

Module vs Package

ModulePackage
Usually ek Python file.Related modules/code ko organize karne ka structure.
Example: calc.pyExample: ek folder/package jisme related modules hon.
Functions/classes/variables contain kar sakta hai.Bade codebase ko logically organize karta hai.

Modular Programming

Large program ko independent logical modules/functions mein divide karna modular programming approach hai. Isse code manageable aur reusable banta hai.

Regular Expressions

import re

text = "My number is 9876543210"

result = re.search(r"\d{10}", text)

if result:
    print("10 digit number found")
else:
    print("Not found")

Exception Handling

Program execute hote waqt kuch unexpected problems aa sakti hain. Aise runtime problems ko handle karne ke liye exception handling use hoti hai. Unit 4 syllabus mein Exception Handling explicitly included hai. fileciteturn47file1

try:
    n = int(input("Enter number: "))
    print(10 / n)
except ZeroDivisionError:
    print("Cannot divide by zero")

try mein risky code aur except mein error handle karne wala code likhte hain.

try-except-else-finally

try:
    x = int(input("Enter x: "))
    result = 10 / x
except ValueError:
    print("Invalid integer")
except ZeroDivisionError:
    print("Zero is not allowed")
else:
    print("Result =", result)
finally:
    print("Program finished")
BlockRole
tryRisky statements.
exceptException handle karta hai.
elseException na aaye to execute hota hai.
finallyGenerally cleanup/final code ke liye execute hota hai.

Common exceptions

  • ValueError — value ka expected format/type conversion issue.
  • TypeError — incompatible operation/type.
  • NameError — undefined name.
  • IndexError — invalid sequence index.
  • KeyError — dictionary mein missing key.
  • ZeroDivisionError — zero se division.

PyPI and pip

PyPI (Python Package Index) Python packages ko publish/share karne ka online repository/ecosystem hai. pip Python packages ko install/manage karne ke liye commonly used package manager command hai. Dono terms Unit 4 syllabus mein specifically listed hain. fileciteturn47file1

pip install package_name

Example ke liye NumPy install karne ke context mein:

pip install numpy

Installation ke baad Python code mein:

import numpy as np
Safety tip: Package install karte waqt trusted package name/source verify karna important hai.

PyPI vs pip

PyPIpip
Package repository/index.Package installation/management tool.
Packages available/published hote hain.Packages install/update/remove karne mein help karta hai.

def reverse_string(text):
    return text[::-1]

s = input("Enter string: ")
print("Reverse =", reverse_string(s))

Practical 2 — Function for Compound Interest

Compound Interest ke common annual-compounding formula ko function mein implement kar sakte hain:

def compound_interest(p, r, t):
    amount = p * (1 + r / 100) ** t
    return amount - p

p = float(input("Principal: "))
r = float(input("Rate (%): "))
t = float(input("Time (years): "))

ci = compound_interest(p, r, t)
print("Compound Interest =", ci)

Yahan p principal, r rate percentage aur t time in years hai.

Practical 3 — Function for Factorial and Combination

SBTE practical mein factorial function ko call karke n!/(r!(n-r)!) calculate karne ko kaha gaya hai. fileciteturn47file0

def factorial(n):
    result = 1
    for i in range(1, n + 1):
        result *= i
    return result

n = int(input("Enter n: "))
r = int(input("Enter r: "))

if 0 <= r <= n:
    combination = factorial(n) // (factorial(r) * factorial(n - r))
    print("nCr =", combination)
else:
    print("Invalid values: require 0 <= r <= n")

Example: 5C2 = 5!/(2!3!) = 10.

Common Errors & Important Differences

1. Function define karke call na karna

def greet():
    print("Hello")

# greet() call karna zaroori hai
greet()

2. Parameter aur argument confuse karna

Definition mein x parameter hai; call mein 10 argument hai.

def square(x):
    return x*x

square(10)

3. return ko print samajhna

return value ko caller ko deta hai; output display karne ke liye zaroorat ho to print() karo.

4. Local variable outside use karna

def demo():
    x = 10

# print(x)  # NameError

5. Module import spelling mistake

import math
print(math.sqrt(25))

6. Exception ko ignore karna

Har possible error ko blindly catch karna useful nahi hota. Specific exceptions ko samajhkar handle karna better practice hai.
