DEEP TOPIC 1

3.1 Binary Tree & Traversals

Binary tree me har node ke maximum two children hote hain. Preorder = Root → Left → Right, Inorder = Left → Root → Right, Postorder = Left → Right → Root. Example tree 1 as root, 2/3 children, 4/5 under 2 ho to preorder 1,2,4,5,3; inorder 4,2,5,1,3; postorder 4,5,2,3,1. BST me left subtree keys smaller aur right subtree keys larger hote hain; BST ka inorder traversal sorted order deta hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 2

3.2 Heap & Priority Queue

Min-heap me parent ≤ children, max-heap me parent ≥ children. Binary heap complete binary tree hota hai aur array me efficiently store kiya ja sakta hai. 0-based indexing me left child=2i+1, right child=2i+2, parent=(i-1)//2. Insert ke baad upward heapify; root deletion ke baad last element root par laakar downward heapify karte hain. Priority queue me dequeue highest-priority element ko return karta hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 3

3.3 Graph Representation

Graph G=(V,E) vertices aur edges ka collection hai. Adjacency matrix V×V table hota hai; edge lookup fast hai but O(V²) space leta hai. Adjacency list har vertex ke neighbours store karti hai aur sparse graph ke liye space-efficient hoti hai. Directed graph me edge direction hoti hai; weighted graph me edge ke saath cost/weight hota hai. Degree, indegree, outdegree aur articulation point important terms hain.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 4

3.4 BFS, DFS & Shortest Path

BFS queue use karke level-by-level traversal karta hai; unweighted graph me BFS shortest number-of-edges path de sakta hai. DFS recursion/stack use karta hai. Dijkstra non-negative edge weights ke liye shortest paths nikalta hai. Bellman-Ford negative edges handle kar sakta hai aur negative cycle detect kar sakta hai. Floyd-Warshall all-pairs shortest paths ke liye dynamic-programming style O(V³) method hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
DEEP TOPIC 5

3.5 MST — Prim & Kruskal

Spanning tree connected graph ke sabhi vertices ko exactly V-1 edges se connect karta hai. Minimum Spanning Tree total edge weight minimum rakhta hai. Prim ek growing tree maintain karke minimum connecting edge choose karta hai. Kruskal globally smallest edges sort karke cycle create na karne wali edge select karta hai; disjoint-set/union-find implementation useful hai.

Exam practice: Definition + working/algorithm + example/dry-run + complexity/important point likho.
