1. Conditional Statement kya hota hai?

Jab program ko kisi condition ke basis par decide karna ho ki konsa code execute hoga, tab conditional statement use karte hain. Condition generally True ya False result deti hai.

marks = 70

if marks >= 40:
    print("Pass")

Agar condition true hai to indented block chalega. False hone par block skip ho jayega.

2. Simple if Statement

Simple if ka use tab karte hain jab sirf ek condition check karni ho.

age = 20

if age >= 18:
    print("Eligible")

Yahan age 18 ya usse zyada hai to message print hoga. Agar condition false hui to kuch bhi print nahi hoga.

3. if-else Statement

Jab do possible cases hon, if-else use karo. Ek block condition true hone par aur doosra false hone par execute hota hai.

n = int(input("Enter number: "))

if n % 2 == 0:
    print("Even")
else:
    print("Odd")

Yahan number 2 se divide karne par remainder 0 hua to Even, warna Odd.

4. if-elif-else

Jab two se zyada possibilities hon, elif use karte hain. Python conditions ko top to bottom check karta hai aur pehli true condition ka block execute karta hai.

marks = int(input("Enter marks: "))

if marks >= 80:
    print("A")
elif marks >= 60:
    print("B")
elif marks >= 40:
    print("C")
else:
    print("Fail")
Important: Conditions ka order important hai. Agar broad condition pehle true ho gayi to neeche wali conditions check nahi hongi.

5. Nested if

Ek if ke andar doosra if ho to use nested if bolte hain. Iska use tab useful hai jab second decision first decision par depend kare.

age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Allowed")
    else:
        print("ID required")
else:
    print("Not eligible")

6. Iterative Statement / Loop kya hai?

Jab same kaam repeatedly karna ho, baar-baar same code likhne ke bajay loop use karte hain. Isse code short aur manageable hota hai.

Start→Condition / Next item→Body execute→Repeat

7. while Loop

while loop tab tak repeat hota hai jab tak uski condition True hai.

i = 1

while i <= 5:
    print(i)
    i += 1

Output 1 se 5 tak aayega. Yahan i += 1 important hai, kyunki value update hone se eventually condition false hoti hai.

Common mistake: while loop mein control variable update nahi kiya to infinite loop ban sakta hai.

8. for Loop

for loop ka use iterable ke items ko one-by-one process karne ke liye hota hai. Numbers ke liye ise range() ke saath bahut use kiya jata hai.

for i in range(1, 6):
    print(i)

Yahan i ko 1, 2, 3, 4 aur 5 values milengi.

9. range() Function

range() integer values ki sequence provide karta hai. Sabse important rule: start included hota hai, stop excluded hota hai.

FormMeaningExample

range(start, stop)start included, stop excluded.range(2,6) → 2,3,4,5

10. break

break current loop ko completely stop kar deta hai.

for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output 1, 2, 3, 4 hoga. 5 aate hi loop terminate ho jayega.

11. continue

continue loop ko completely stop nahi karta. Sirf current iteration skip karta hai aur next iteration par chala jata hai.

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output 1, 2, 4, 5 hoga.

breakcontinue
Poora loop stop.Sirf current iteration skip.
Control loop ke bahar.Control next iteration par.

12. Nested Loop

Jab ek loop ke andar doosra loop ho, use nested loop bolte hain. Outer loop ki har iteration ke liye inner loop apni iterations perform karta hai.

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

Nested loops ka use patterns, tables aur multi-level repetition problems mein hota hai.

Decision Making — Basic Concept

A normal program executes statements in sequence. But real problems often require a choice: “If marks are 40 or more, print Pass; otherwise print Fail.” Python provides conditional statements for such decisions.

A condition is an expression that produces a Boolean result, normally True or False.

marks = 65
print(marks >= 40)
True

Once a condition produces a Boolean value, a decision-making statement can use it to determine which block should execute.

Condition building blocks

TypeExamplePurpose
Comparisonx > 10Compares values.
Equalityx == 10Checks whether values are equal.
Logical ANDx>0 and x<10Requires both conditions to be true.
Logical ORx==0 or x==1Requires at least one condition to be true.
Logical NOTnot passedReverses a Boolean result.

Indentation is part of the block

Python uses indentation to show which statements belong to a conditional or loop block.

marks = 75

if marks >= 40:
    print("Pass")
    print("Congratulations")

print("Program continues")

The two indented print() statements belong to the if block. The last statement is outside that block.

Important Do not randomly mix indentation levels. A block must have consistent indentation.

2.1 Simple if Statement

The simple if statement executes a block only when its condition is true.

Syntax

if condition:
    statement1
    statement2

The colon : starts the block, and the indented statements form the body.

Flow of execution

Evaluate condition→True?→Execute block→Continue

If the condition is false, Python skips the indented block and continues with the next statement after it.

Example 1 — Check positive number

number = 10

if number > 0:
    print("Positive number")

Example 2 — Check eligibility

age = 20

if age >= 18:
    print("Eligible")

Example 3 — Even number

number = 24

if number % 2 == 0:
    print("Even number")

The expression number % 2 == 0 checks whether the remainder after division by 2 is zero.

Algorithm for simple if

  1. Start.
  2. Read the required input.
  3. Evaluate the condition.
  4. If the condition is true, execute the block.
  5. Continue with the next statement.
  6. Stop.

Important point

A simple if does not provide an alternative block. It either executes the block or skips it.

if-else Statement

Use if-else when exactly two alternatives are required: one block for a true condition and another for a false condition.

Syntax

if condition:
    statements_for_true
else:
    statements_for_false

Example — Pass or Fail

marks = int(input("Enter marks: "))

if marks >= 40:
    print("Pass")
else:
    print("Fail")

Execution logic

Condition→True → if block/False → else block

Only one of the two blocks executes for a particular evaluation.

Example — Even or Odd

n = int(input("Enter a number: "))

if n % 2 == 0:
    print("Even")
else:
    print("Odd")

Example — Larger of two numbers

a = int(input("Enter a: "))
b = int(input("Enter b: "))

if a > b:
    print("A is larger")
else:
    print("B is larger")
Edge case If the problem allows equal values, a plain greater-than comparison should be designed carefully. For example, when finding the larger value, an equal case may need separate handling if the question asks for it explicitly.

if-elif-else Statement

When there are more than two possible conditions, Python provides elif, meaning “else if”.

Syntax

if condition1:
    block1
elif condition2:
    block2
elif condition3:
    block3
else:
    default_block

Python checks the conditions from top to bottom. When the first true condition is found, its block executes and the remaining alternatives are skipped.

Example — Grade

marks = int(input("Enter marks: "))

if marks >= 80:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")

Why order matters

Suppose the conditions were written from low to high:

if marks >= 40:
    print("C")
elif marks >= 60:
    print("B")
elif marks >= 80:
    print("A")

For 85 marks, the first condition is already true, so Python would print C. Therefore, overlapping ranges should normally be arranged from the most restrictive/highest threshold to the lower thresholds when that matches the intended grading logic.

Memory rule if = first possibility, elif = additional possibilities, else = remaining case.

Example — Positive, Negative or Zero

n = float(input("Enter a number: "))

if n > 0:
    print("Positive")
elif n < 0:
    print("Negative")
else:
    print("Zero")

Nested Decision Making

A conditional statement placed inside another conditional block is called a nested conditional statement.

age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Allowed")
    else:
        print("ID required")
else:
    print("Not eligible")

Nested conditions should be used when the second decision depends on the first decision.

Nested vs elif

Nested ifif-elif-else
One decision is placed inside another.Several alternatives are checked at the same level.
Useful for dependent decisions.Useful for mutually exclusive choices.

2.2 Iterative Statements

An iterative statement repeats a set of instructions. Loops are useful when the same operation must be performed many times.

For example, instead of writing:

print(1)
print(2)
print(3)
print(4)
print(5)

a loop can express the repeated pattern more compactly.

Start→Check / get next item→Execute body→Repeat

Two main loops in Unit 2

LoopBasic ideaCommon use
whileRepeat while a condition is true.Condition-controlled repetition.
forIterate over items of an iterable/sequence or a generated range.Known/counted repetition and sequence traversal.

while Loop

The while loop repeatedly executes its body as long as its condition remains true.

Syntax

while condition:
    statements

Basic example

i = 1

while i <= 5:
    print(i)
    i += 1

Output:

1
2
3
4
5

Step-by-step execution

  1. i starts at 1.
  2. Python checks i <= 5.
  3. The body prints the current value.
  4. i increases by 1.
  5. The condition is checked again.
  6. When i becomes 6, the condition is false and the loop ends.

Important: update the loop variable

A condition-controlled loop must eventually become false unless an intentionally infinite loop is required. Forgetting to update the control variable can create an infinite loop.

# Risk of infinite repetition
i = 1
while i <= 5:
    print(i)
    # i += 1 is missing
Common mistake In a while loop, always check whether the condition can eventually become false.

while loop for sum

n = int(input("Enter n: "))
i = 1
total = 0

while i <= n:
    total += i
    i += 1

print("Sum =", total)

while loop for countdown

i = 5
while i >= 1:
    print(i)
    i -= 1

print("Start!")

while loop with user-controlled repetition

choice = "y"

while choice == "y":
    print("Task executed")
    choice = input("Continue? (y/n): ")

This illustrates a condition that depends on user input.

for Loop

The for loop is used to iterate over items produced by an iterable. In beginner programs, it is often combined with range() for counted repetition.

Syntax

for variable in iterable:
    statements

Example — sequence of numbers

for i in range(1, 6):
    print(i)

Example — string traversal

word = "PYTHON"

for ch in word:
    print(ch)

Each iteration assigns the next character to ch.

Example — list traversal

marks = [70, 82, 91]

for mark in marks:
    print(mark)

for vs while

forwhile
Convenient when iterating over a sequence/range.Convenient when repetition depends on a condition.
Loop variable is naturally advanced by iteration.Programmer normally updates the control state.
Often used for counted repetition.Often used for condition-controlled repetition.

range() Function

range() produces a sequence of integers that can be iterated over. It is commonly used with for.

Forms of range()

FormMeaningExample
range(stop)Starts at 0 and goes up to, but does not include, stop.range(5) → 0,1,2,3,4
range(start, stop)Starts at start and excludes stop.range(2,6) → 2,3,4,5
range(start, stop, step)Moves by step.range(2,10,2) → 2,4,6,8

Very important: stop is excluded

for i in range(1, 6):
    print(i)

This prints 1 through 5, not 6.

Step value

for i in range(2, 11, 2):
    print(i)

Output:

2
4
6
8
10

Reverse range

for i in range(5, 0, -1):
    print(i)

The negative step moves from larger numbers to smaller numbers.

Exam trick For range(a, b), remember “start included, stop excluded.”

break and continue Statements

break

break immediately terminates the nearest enclosing loop. Control moves to the statement after that loop.

for i in range(1, 10):
    if i == 5:
        break
    print(i)

Output:

1
2
3
4

continue

continue skips the remaining statements of the current iteration and moves to the next iteration of the nearest enclosing loop.

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

Output:

1
2
4
5

break vs continue

StatementEffect
breakEnds the loop completely.
continueSkips only the current iteration.

while + break example

while True:
    n = int(input("Enter 0 to stop: "))
    if n == 0:
        break
    print("You entered:", n)

Nested Loops

A loop inside another loop is called a nested loop. For every iteration of the outer loop, the inner loop normally completes its own iterations.

Basic example

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

The outer loop controls i. For each value of i, the inner loop runs through its values of j.

Pattern example

for i in range(1, 5):
    for j in range(i):
        print("*", end=" ")
    print()

Output:

* 
* * 
* * * 
* * * *

Multiplication table using nested thinking

for i in range(1, 6):
    for j in range(1, 6):
        print(i * j, end="	")
    print()
Performance note Nested loops can execute many times. If the outer loop runs n times and the inner loop also runs about n times, the body may execute roughly n×n times.

Program 3 — Print Prime Numbers in an Interval

A prime number greater than 1 has exactly two positive divisors: 1 and itself.

Logic

For each number in the interval, test whether it has a divisor other than 1 and itself. A simple beginner-friendly method checks divisors from 2 up to a suitable limit.

start = int(input("Enter start: "))
end = int(input("Enter end: "))

for n in range(start, end + 1):
    if n < 2:
        continue

    is_prime = True

    for d in range(2, n):
        if n % d == 0:
            is_prime = False
            break

    if is_prime:
        print(n, end=" ")

Sample

Enter start: 10
Enter end: 20
11 13 17 19
Why break? Once a divisor is found, the number is known to be non-prime, so there is no need to test more divisors.

Program 5 — Fibonacci Sequence

In the common Fibonacci sequence, each new term is obtained by adding the previous two terms. A typical starting sequence is 0, 1, 1, 2, 3, 5, ...

n = int(input("Enter number of terms: "))

a = 0
b = 1

for i in range(n):
    print(a, end=" ")
    a, b = b, a + b

Sample

Enter number of terms: 8
0 1 1 2 3 5 8 13
Core update Before each iteration, a is the current term and b is the next term. The assignment a, b = b, a+b advances both values together.

Program 6 — Factorial of a Number

The factorial of a non-negative integer n is the product of all positive integers from 1 to n. It is written as n!.

For example, 5! = 5×4×3×2×1 = 120. Also, 0! = 1.

n = int(input("Enter a non-negative integer: "))

factorial = 1

if n < 0:
    print("Factorial is not defined for negative integers")
else:
    for i in range(1, n + 1):
        factorial *= i
    print("Factorial =", factorial)

Sample

Enter a non-negative integer: 5
Factorial = 120

Common Errors & Debugging

1. Missing colon

# Wrong
if x > 5
    print(x)

# Correct
if x > 5:
    print(x)

2. Wrong indentation

# Correct structure
if marks >= 40:
    print("Pass")
    print("Result recorded")

3. Infinite while loop

i = 1
while i <= 5:
    print(i)
    i += 1

Always check how the loop condition changes.

4. Incorrect range expectation

range(1, 5)

produces 1, 2, 3, 4 — the stop value 5 is excluded.

5. Using break when continue is needed

If you want to skip only one case, use continue. If you want to terminate the loop, use break.

6. Wrong elif ordering

When conditions overlap, place the conditions in an order that matches the intended decision logic. Test boundary values such as 0, 1, 40, 59, 60, 79 and 80 when building a grading program.

7. Forgetting input conversion

age = int(input("Enter age: "))

Use a suitable conversion when arithmetic or numeric comparison is required.

Q: What does continue do?
A: It skips the remaining body of the current iteration and starts the next iteration.
