1.1 Operating System: Concept, Components & System Software

Operating System (OS) ek system software hai jo user/application programs aur computer hardware ke beech interface provide karta hai. Iska main role CPU, memory, storage aur I/O devices jaise resources ko manage karna aur applications ko controlled execution environment dena hai.

Major components: process management, memory management, file-system management, I/O/device management, secondary-storage management, protection/security aur command/user interface. System software ka broader group OS ke saath utilities, device drivers aur language-support tools ko include kar sakta hai.

1.2 Functions of OS

  • Program management: program ko load, execute aur terminate karna.
  • Resource management: CPU, memory, devices aur storage ko processes ke beech allocate karna.
  • File management: files/directories create, delete, organize aur access control.
  • Device management: drivers, I/O requests aur device allocation ko handle karna.
  • Security & protection: unauthorized access ko control karna aur resources isolate karna.

1.3 User View vs System View

User ViewSystem View
Convenience, responsiveness aur applications ko run karne par focus.Resource allocator aur control program ke roop mein OS ko dekhta hai.
Example: file open karna, app launch karna.Example: CPU time, memory frame aur I/O device allocate karna.

1.4 Types of Operating Systems

  • Batch OS: jobs ko batches mein collect karke user interaction ke bina execute karta hai.
  • Multiprogramming OS: multiple jobs memory mein rakhta hai aur CPU ko busy rakhne ke liye jobs ke beech switch karta hai.
  • Time-shared OS: CPU time ko small time slices mein divide karke interactive users/processes ko response deta hai.
  • Multiprocessing OS: multiple processors/cores ka use karke parallel execution support karta hai.
  • Distributed OS: networked computers ke resources ko coordinated system ki tarah present kar sakta hai.
  • Real-time OS: timing constraints important hote hain; real-time response predictable hona chahiye.
  • Mobile OS: mobile hardware, touch interface, power constraints, sensors aur wireless resources ko manage karta hai.

1.5 OS Services

Common services mein program execution, I/O operations, file-system manipulation, communication, error detection, resource allocation, accounting aur protection/security shamil hote hain. Exam mein service ka naam + one-line purpose likhna useful hai.

1.6 System Calls

System call application program ka OS kernel se service request karne ka controlled mechanism hai. Typical categories: process control, file management, device management, information maintenance aur communication/protection.

Application → API / system-call interface → Kernel → Hardware/resource → Result back to application

Example idea: program file open/read karna chahta hai; request kernel ko jaati hai, OS permissions aur resource checks karta hai, operation perform karta hai aur result return karta hai.

⚡ Quick Revision

OS = Interface + Resource Manager + Control Program. Functions: program, resource, file, device, security/protection. Services: execution, I/O, files, communication, error detection, allocation, accounting, protection. System calls user program ko kernel services tak controlled access dete hain.

Unit 1 — Operating System Fundamentals

Definition se system calls tak — concepts, examples, diagrams aur exam-ready answers.

1.1 Operating System kya hai?

Operating System ek system software hai jo user/application aur computer hardware ke beech interface provide karta hai. Ye CPU, memory, storage aur I/O devices jaise resources ko manage karta hai aur programs ko execution environment deta hai.

Simple model: User → Application → Operating System → Hardware.

1.2 Main Functions

  • Process management
  • Memory management
  • File/storage management
  • I/O and device management
  • Protection/security
  • Resource allocation

1.3 OS Components

Kernel core control layer hota hai. Process manager, memory manager, file system, device drivers, networking and security mechanisms OS ke important parts hain. User shell/GUI ke through services access kar sakta hai.

1.4 Types of Operating Systems

Batch: jobs batches me process. Time-sharing: interactive users ko CPU time slices. Real-time: timing constraints important. Distributed: multiple machines coordinated environment. Network OS: network resource/services. Embedded/mobile: specialized devices with constrained resources.

1.5 OS Services

Program execution, I/O operations, file manipulation, communication, error detection, resource allocation, accounting and protection are common services.

1.6 System Calls

Application directly hardware control nahi karti; system call interface ke through kernel service request karti hai. Categories: process control, file management, device management, information maintenance and communication.

   ↓ system call

1.7 Kernel Mode vs User Mode

Normal application restricted user mode me chalti hai. Privileged instructions/kernel resources ke liye controlled transition kernel mode me hota hai. Is separation se accidental/malicious misuse ko limit kiya ja sakta hai.
