Scope: Propositional logic, truth tables, tautologies/contradictions, equivalences; predicate logic with quantifiers/nested quantifiers; direct, contrapositive, contradiction and mathematical induction. This follows the SBTE Unit 1 syllabus. fileciteturn307file0

1.1 Propositional Logic

A proposition is a declarative statement having exactly one truth value: True or False. Basic connectives are NOT (¬p), AND (p∧q), OR (p∨q), implication (p→q) and biconditional (p↔q).

Truth-value rulesp→q is false only when p is True and q is False. p↔q is true when both have the same truth value.

Tautology: always true. Contradiction: always false. Logical equivalence: p and q are equivalent when p↔q is a tautology. Useful laws include double negation, identity, domination, idempotent, complement, commutative, associative, distributive and De Morgan's laws.

1.2 Predicate Logic

A predicate contains variables whose truth depends on the value assigned. Quantifiers make the statement precise: ∀x means “for every x”; ∃x means “there exists an x”. Nested quantifiers combine scopes, so order matters.

Example“Every student has an ID” can be represented as ∀x(Student(x) → HasID(x)).

1.3 Proof Techniques

  • Direct: assume the hypothesis and logically derive the conclusion.
  • Contrapositive: prove ¬Q → ¬P instead of P → Q.
  • Contradiction: assume the claim is false and derive an inconsistency.
  • Induction: prove a base case, assume P(k), then prove P(k+1).
Exam patternTruth table + equivalence simplification + quantifier translation + one proof/induction problem.

Quick Revision

Proposition → connectives → truth table → tautology/contradiction → equivalence → predicates/quantifiers → proof methods → induction.

Unit 1 — Logic, Propositions & Proof Techniques

Truth tables se predicate logic, inference aur induction tak.

1.1 Propositions & Connectives

Proposition ek declarative statement hai jo exactly true ya false ho. NOT ¬p, AND p∧q, OR p∨q, implication p→q aur biconditional p↔q basic connectives hain.

p→q sirf p=T aur q=F par false hota hai.

1.2 Truth Tables

n variables ke liye 2n rows. Har combination evaluate karke compound statement ka final truth column banao.

p q | p→q
T T | T
T F | F
F T | T
F F | T

1.3 Tautology, Contradiction

Tautology always true; contradiction always false; contingency mixed truth values. p∨¬p tautology aur p∧¬p contradiction hai.

1.4 Logical Equivalence

p≡q when every assignment gives same truth value. De Morgan: ¬(p∧q)≡¬p∨¬q and ¬(p∨q)≡¬p∧¬q. Equivalence truth table ya logical laws se prove karo.

1.5 Predicate & Quantifiers

Predicate variable-containing statement form hai. ∀ means for all; ∃ means there exists. Quantifier ka domain clearly mention karo.

1.6 Nested Quantifiers

∀x∃y P(x,y) aur ∃y∀x P(x,y) generally same meaning nahi rakhte. Quantifier order carefully interpret karo.

1.7 Inference Rules

Modus Ponens: p, p→q ⇒ q. Modus Tollens: ¬q, p→q ⇒ ¬p. Premises se conclusion ka valid logical path show karo.

1.8 Proof Techniques

Direct: hypothesis se conclusion. Contrapositive: ¬q→¬p. Contradiction: opposite assume karke contradiction.

1.9 Induction

Base case verify → P(k) assume → P(k+1) prove. Example: 1+2+…+n=n(n+1)/2.

P(1)
Assume P(k)
Prove P(k+1)
