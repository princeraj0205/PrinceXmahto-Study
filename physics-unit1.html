1.1 Physical Quantities, Fundamental and Derived Units, and System of Units

1.1.1 Physical Quantity

Definition: A physical quantity is a measurable property of a physical body, phenomenon or system that can be expressed by a numerical value together with a unit.

Examples are length, mass, time, temperature, electric current and speed.

Every measured physical quantity can be written in the form:

Physical quantity = Numerical value × Unit
Example: If the length of a wire is 2 m, then 2 is the numerical value and metre (m) is the unit.

1.1.2 Measurement

Definition: Measurement is the process of comparing an unknown physical quantity with an accepted standard of the same kind.

For example, when we say a table is 1.5 m long, its length has been compared with the standard unit metre.

1.1.3 Unit

Definition: A unit is an accepted standard quantity used as a reference for measuring a physical quantity of the same kind.

A good standard unit should be well defined, reproducible, stable, accessible and convenient to use.

Definition: Fundamental physical quantities are independent physical quantities that are not defined in terms of other physical quantities.

1.2 Accuracy, Precision, Errors, Error Estimation, Propagation of Errors and Significant Figures

1.2.1 Accuracy

Definition: Accuracy is the degree of closeness of a measured value to the true or accepted value of the physical quantity.

If the true length is 10.00 cm and an instrument gives 9.99 cm, the measurement is highly accurate.

1.2.2 Precision

Definition: Precision is the degree of agreement among repeated measurements of the same quantity.

A set of readings can be precise but not accurate if they are close to each other but far from the accepted value.

AccuracyPrecision
Closeness to true/accepted value.Closeness among repeated readings.
Related to correctness.Related to repeatability.

1.2.3 Error

Definition: Error is the difference between a measured value and the true or accepted value of a physical quantity.

Error is not necessarily a mistake. In measurement, unavoidable limitations of instruments, environment and observation can produce errors.

1.2.4 Systematic Error

Definition: A systematic error is an error that tends to occur in a definite, consistent pattern and often produces a bias in one direction.

Sources include zero error, calibration error, instrumental error and certain environmental effects.

Example: If a weighing instrument always reads 0.20 kg higher, that bias is systematic.

1.2.5 Random Error

Definition: A random error is an unpredictable variation in measured values that changes in magnitude and/or direction from one measurement to another.

Repeated measurements and averaging can reduce the influence of random errors.

1.2.6 Absolute Error

If the accepted/true value is x and measured value is xₘ:

Absolute error = |xₘ − x|

For repeated measurements x₁, x₂, ..., xₙ, the mean value is:

x̄ = (x₁ + x₂ + ... + xₙ) / n

The absolute error of an individual reading can be written as:

Δxᵢ = |xᵢ − x̄|

Mean absolute error:

Mean absolute error = (Δx₁ + Δx₂ + ... + Δxₙ) / n
Solved Example:
Readings of length are 10.2 cm, 10.4 cm and 10.3 cm.
Mean = (10.2 + 10.4 + 10.3)/3 = 10.3 cm.
Absolute errors = 0.1 cm, 0.1 cm and 0 cm.
Mean absolute error = 0.2/3 = 0.0667 cm ≈ 0.07 cm.
So the result may be written approximately as 10.30 ± 0.07 cm, depending on the required reporting convention.

1.2.7 Relative Error

Definition: Relative error is the ratio of the absolute error to the measured/mean value.
Relative error = Δx / x̄

1.2.8 Percentage Error

Percentage error = (Δx / x̄) × 100%
Example: If x = 50 cm and Δx = 0.5 cm, relative error = 0.5/50 = 0.01 and percentage error = 1%.

1.2.9 Propagation of Errors

When a quantity is calculated from measured quantities, the uncertainties/errors in the measured quantities affect the calculated result.

Case A: Addition or Subtraction

If z = x ± y, then maximum absolute error: Δz = Δx + Δy

Case B: Multiplication or Division

If z = xy or z = x/y, then Δz/z = Δx/x + Δy/y

Case C: Power

If z = xⁿ, then Δz/z = |n| Δx/x

Case D: General Product/Power Form

If z = xᵃ yᵇ / wᶜ, then Δz/z ≈ |a|Δx/x + |b|Δy/y + |c|Δw/w
Example: If A = l × b, then the maximum fractional error is ΔA/A = Δl/l + Δb/b.

1.2.10 Significant Figures

Definition: Significant figures are the meaningful digits in a measured quantity that convey its precision.

Examples:

  • 25.4 has 3 significant figures.
  • 0.0045 has 2 significant figures.
  • 2.500 has 4 significant figures.
  • 100.0 has 4 significant figures when the decimal notation indicates measured precision.

Rules

  1. All non-zero digits are significant.
  2. Zeros between non-zero digits are significant.
  3. Leading zeros are not significant.
  4. Trailing zeros after a decimal point are significant.
  5. Use scientific notation when the number of significant figures could otherwise be ambiguous.

Rounding Off

If the first discarded digit is less than 5, the retained digit is unchanged. If it is 5 or greater, the retained digit is increased by one, subject to the adopted rounding convention.

Common mistake: Do not automatically treat every zero as significant. Its position matters.

1.3.3 Principle of Homogeneity of Dimensions

Statement: In a physically meaningful equation, the dimensions of every term that is added or subtracted must be the same, and the dimensions of the left-hand side must equal the dimensions of the right-hand side.
Check: v = u + at
[v] = LT⁻¹.
[u] = LT⁻¹.
[a t] = (LT⁻²)(T) = LT⁻¹.
Therefore all terms have the same dimensions and the equation is dimensionally homogeneous.
Important limitation: Dimensional analysis can check dimensional consistency, but dimensional consistency alone does not prove that an equation is physically correct. Numerical constants and some mathematical functions cannot be determined by dimensions alone.

1.4 Applications of Dimensions

1.4.1 Conversion from One System of Units to Another

Dimensional analysis can be used to convert a physical quantity from one unit system to another.

Example: Convert 72 km/h into m/s.
72 km/h = 72 × (1000 m)/(3600 s)
= 20 m/s.
Answer: 20 m/s.

1.4.2 Checking/Correcting Equations

If an equation contains terms that are added or subtracted, each such term must have identical dimensions.

Example: s = ut + ½at².
[ut] = (LT⁻¹)(T) = L.
[at²] = (LT⁻²)(T²) = L.
[s] = L.
Hence it is dimensionally homogeneous.

1.4.3 Derivation of a Simple Equation

Suppose the time period T of a simple pendulum is assumed to depend on length l and gravitational acceleration g:

T ∝ lᵃ gᵇ

Dimensions:

[T] = [L]ᵃ [LT⁻²]ᵇ = Lᵃ⁺ᵇ T⁻²ᵇ

Comparing powers:

  • For L: 0 = a + b
  • For T: 1 = −2b

Therefore b = −1/2 and a = 1/2.

T ∝ √(l/g)

Dimensional analysis cannot determine the dimensionless numerical constant. The known physical result is T = 2π√(l/g), but the factor 2π comes from the full physical derivation.

1.4.4 Typical Dimensional Analysis Workflow

  1. Write the quantity to be found.
  2. Assume dependence on the relevant physical variables.
  3. Introduce unknown powers.
  4. Write dimensions of both sides.
  5. Compare powers of fundamental dimensions.
  6. Solve the simultaneous equations.
  7. State the result and remember that dimensionless constants may remain undetermined.
Exam focus: Practice one unit-conversion problem, one equation-checking problem and one simple derivation by dimensions.

1.5 Ancient Astronomical Instruments (IKS)

The syllabus specifically includes four ancient astronomical instruments: Chakra, Dhanuryatra, Yasti and Phalaka Yantra. These are included under Indian Knowledge Systems (IKS).

1.5.1 Chakra

Study definition: Chakra is an astronomical instrument based on circular/angular measurement concepts, used in traditional observational astronomy.

Its educational importance is the use of geometric/angular relationships for observing celestial positions.

1.5.2 Dhanuryatra

Study definition: Dhanuryatra is a traditional astronomical observation instrument associated with angular measurement, using an arc/bow-like arrangement.

The name reflects a bow-shaped geometric form. In exam answers, connect it with traditional astronomical observation and angular measurement rather than adding unsupported construction details.

1.5.3 Yasti

Study definition: Yasti is a traditional observational instrument based on a graduated staff/rod concept for measuring or determining angular/astronomical quantities.

Its underlying idea is simple: a known geometrical reference can be used to make observations of celestial objects.

1.5.4 Phalaka Yantra

Study definition: Phalaka Yantra is a traditional astronomical instrument associated with a plane/board-like arrangement for astronomical observation and measurement.

For the Diploma exam, remember the instrument names and their broad purpose: traditional Indian astronomical observation and measurement.

Worked Exam Numericals

Numerical 1 — Percentage Error

Question: A measured length is 25.0 cm and its absolute error is 0.2 cm. Find percentage error.

Given: x = 25.0 cm, Δx = 0.2 cm

Formula:

% error = (Δx/x) × 100

Substitution: (0.2/25.0) × 100 = 0.8%

Answer: 0.8%

Numerical 2 — Relative Error

Question: Mean measured value is 40 cm and absolute error is 0.4 cm.

Relative error = 0.4/40 = 0.01

Answer: 0.01

Numerical 3 — Dimensional Formula of Force

Question: Find the dimensional formula of force.

Force = mass × acceleration.

[F] = [M] [LT⁻²] = [MLT⁻²]

Answer: [MLT⁻²]

Numerical 4 — Dimensional Formula of Pressure

Pressure = force/area.

[P] = [MLT⁻²] / [L²] = [ML⁻¹T⁻²]

Answer: [ML⁻¹T⁻²]

Numerical 5 — Unit Conversion

Question: Convert 90 km/h into m/s.

90 × 1000/3600 = 25 m/s

Answer: 25 m/s

Common Mistakes in Unit 1

  • Writing unit without a numerical value when a measured result is asked.
  • Confusing accuracy with precision.
  • Forgetting the absolute-value sign in absolute error.
  • Using percentage error formula without multiplying by 100.
  • Mixing dimensions and units.
  • Writing the dimension of force as [MLT] instead of [MLT⁻²].
  • Forgetting that terms being added/subtracted must have the same dimensions.
  • Assuming dimensional analysis can determine numerical constants such as 2π.
  • Ignoring significant figures while reporting measured results.
  • Adding unsupported construction details to IKS instrument answers.
