Unit 1 — Number Systems, Boolean Algebra and Logic Gates

SBTE scope: binary/octal/decimal/hex conversion and arithmetic, 1's/2's complements, negative-number representation, Boolean laws, De Morgan, SOP/POS, 3-variable K-map and logic gates. fileciteturn307file3

Number Systems & Conversion

Binary uses base 2, octal base 8, decimal base 10 and hexadecimal base 16. Decimal-to-binary is commonly done by repeated division by 2; binary-to-octal groups bits in threes and binary-to-hex groups bits in fours.

Complements & Subtraction

For an n-bit binary number, the 1's complement is obtained by changing 0↔1. The 2's complement is 1's complement + 1. Signed negative values can be represented using these complement systems. Complement arithmetic allows subtraction to be performed through addition with the appropriate complement.

Boolean Algebra, SOP & POS

Important laws include identity, null, idempotent, complement, absorption, distributive and De Morgan's laws. SOP is OR of product terms; POS is AND of sum terms.

K-map

For up to three variables, place minterms in Gray-code order, group adjacent 1s in powers of two (1,2,4…), make groups as large as possible and write the simplified expression from variables that remain constant within each group.

Logic Gates

AND, OR and NOT are basic gates. NAND and NOR are universal gates. XOR gives 1 when inputs differ; XNOR gives 1 when inputs are equal. In an exam, draw symbol + truth table + expression + one application.

Exam focusConversions, binary arithmetic, 1's/2's complement subtraction, Boolean simplification, SOP/POS, 2/3-variable K-map and gate truth tables.
